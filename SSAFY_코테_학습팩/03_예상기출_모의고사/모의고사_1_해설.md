# 예상기출 모의고사 1 해설

## M01. 구역 점수 최대값

직사각형 합을 여러 번 구하므로 2차원 누적합을 만든다. 쿼리 좌표가 1부터 시작하므로 누적합 배열도 1-index처럼 쓰면 편하다.

```python
T = int(input())
for tc in range(1, T + 1):
    N, Q = map(int, input().split())
    board = [list(map(int, input().split())) for _ in range(N)]
    prefix = [[0] * (N + 1) for _ in range(N + 1)]

    for r in range(1, N + 1):
        for c in range(1, N + 1):
            prefix[r][c] = (
                prefix[r - 1][c]
                + prefix[r][c - 1]
                - prefix[r - 1][c - 1]
                + board[r - 1][c - 1]
            )

    ans = -10**18
    for _ in range(Q):
        r1, c1, r2, c2 = map(int, input().split())
        total = (
            prefix[r2][c2]
            - prefix[r1 - 1][c2]
            - prefix[r2][c1 - 1]
            + prefix[r1 - 1][c1 - 1]
        )
        ans = max(ans, total)

    print(f"#{tc} {ans}")
```

## M02. 응급 통로

벽을 부쉈는지 여부가 상태에 포함된다. 따라서 방문 배열은 `visited[r][c][broken]` 형태로 둔다. `broken=0`은 아직 벽을 안 부순 상태, `broken=1`은 이미 부순 상태다.

```python
from collections import deque

dr = [-1, 1, 0, 0]
dc = [0, 0, -1, 1]

T = int(input())
for tc in range(1, T + 1):
    N, M = map(int, input().split())
    board = [list(map(int, input().strip())) for _ in range(N)]
    dist = [[[-1] * 2 for _ in range(M)] for _ in range(N)]
    q = deque([(0, 0, 0)])
    dist[0][0][0] = 0

    while q:
        r, c, broken = q.popleft()
        for d in range(4):
            nr = r + dr[d]
            nc = c + dc[d]
            if not (0 <= nr < N and 0 <= nc < M):
                continue

            if board[nr][nc] == 0 and dist[nr][nc][broken] == -1:
                dist[nr][nc][broken] = dist[r][c][broken] + 1
                q.append((nr, nc, broken))
            elif board[nr][nc] == 1 and broken == 0 and dist[nr][nc][1] == -1:
                dist[nr][nc][1] = dist[r][c][broken] + 1
                q.append((nr, nc, 1))

    candidates = [x for x in dist[N - 1][M - 1] if x != -1]
    ans = min(candidates) if candidates else -1
    print(f"#{tc} {ans}")
```

## M03. 최고 점수 조합

N이 작으면 DFS로 선택/미선택을 모두 본다. N이 크면 0/1 배낭 DP로 푸는 것이 좋다. 여기서는 실전 안정성을 위해 DP 풀이를 사용한다.

```python
T = int(input())
for tc in range(1, T + 1):
    N, L = map(int, input().split())
    dp = [0] * (L + 1)

    for _ in range(N):
        score, time = map(int, input().split())
        for cur in range(L, time - 1, -1):
            dp[cur] = max(dp[cur], dp[cur - time] + score)

    print(f"#{tc} {max(dp)}")
```

## M04. 연결 구역 분석

격자의 모든 칸을 돌며 아직 방문하지 않은 1을 만나면 BFS를 시작한다. BFS 한 번이 연결 구역 하나다.

```python
from collections import deque

dr = [-1, 1, 0, 0]
dc = [0, 0, -1, 1]

T = int(input())
for tc in range(1, T + 1):
    N, M = map(int, input().split())
    board = [list(map(int, input().split())) for _ in range(N)]
    visited = [[False] * M for _ in range(N)]
    areas = 0
    max_size = 0

    for sr in range(N):
        for sc in range(M):
            if board[sr][sc] == 0 or visited[sr][sc]:
                continue

            areas += 1
            size = 1
            visited[sr][sc] = True
            q = deque([(sr, sc)])

            while q:
                r, c = q.popleft()
                for d in range(4):
                    nr = r + dr[d]
                    nc = c + dc[d]
                    if 0 <= nr < N and 0 <= nc < M:
                        if board[nr][nc] == 1 and not visited[nr][nc]:
                            visited[nr][nc] = True
                            size += 1
                            q.append((nr, nc))

            max_size = max(max_size, size)

    print(f"#{tc} {areas} {max_size}")
```
