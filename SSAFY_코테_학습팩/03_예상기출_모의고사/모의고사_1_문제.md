# 예상기출 모의고사 1

권장 시간: 120분

목표:

- 1번은 반드시 20분 안에 맞힌다.
- 2번은 BFS 상태 관리를 연습한다.
- 3번은 부분집합/배낭형 사고를 연습한다.
- 4번은 연결 요소 탐색을 안정적으로 구현한다.

## M01. 구역 점수 최대값

N x N 점수판과 Q개의 직사각형 구역이 주어진다. 각 구역의 점수 합 중 최댓값을 출력하라.

직사각형은 `r1 c1 r2 c2`로 주어지고, 좌표는 1부터 시작한다. `r2`, `c2`는 포함된다.

예시:

```text
입력
1
3 2
1 2 3
4 5 6
7 8 9
1 1 2 2
2 2 3 3

출력
#1 28
```

## M02. 응급 통로

N x M 지도가 주어진다. `0`은 이동 가능, `1`은 벽이다. 왼쪽 위에서 오른쪽 아래까지 이동하려고 한다. 상하좌우로 이동할 수 있고, 벽은 최대 한 번 부술 수 있다. 최소 이동 횟수를 구하라. 시작 칸에서 도착 칸까지 이동한 간선 수를 출력하고, 불가능하면 -1을 출력한다.

예시:

```text
입력
1
3 4
0100
1110
0000

출력
#1 5
```

## M03. 최고 점수 조합

N개의 문제가 있다. 각 문제는 점수 S와 풀이 시간 T를 가진다. 총 풀이 시간이 L을 넘지 않도록 문제를 골랐을 때 얻을 수 있는 최대 점수를 출력하라.

예시:

```text
입력
1
4 10
5 3
6 4
10 7
7 5

출력
#1 15
```

## M04. 연결 구역 분석

N x M 격자에 0과 1이 적혀 있다. 1로 이루어진 연결 구역의 개수와, 가장 큰 연결 구역의 크기를 구하라. 연결은 상하좌우 기준이다.

예시:

```text
입력
1
4 5
1 1 0 0 1
0 1 0 1 1
0 0 0 0 0
1 0 1 1 1

출력
#1 4 3
```
