## P01. 홀수 합과 평균

핵심은 한 번 순회하면서 홀수만 더하고, 전체 합으로 평균을 계산하는 것이다. Python의 `round()`는 정확히 `.5`일 때 일반적인 코딩테스트 반올림과 다르게 동작할 수 있으므로 `int(x + 0.5)` 방식을 쓴다.

```python
T = int(input())
for tc in range(1, T + 1):
    N = int(input())
    arr = list(map(int, input().split()))
    odd_sum = 0
    total = 0
    for x in arr:
        total += x
        if x % 2 == 1:
            odd_sum += x
    avg = int(total / N + 0.5)
    print(f"#{tc} {odd_sum} {avg}")
```

## P02. 알파벳 점수 합

`ord("A")`를 기준으로 문자 점수를 계산한다.

```python
T = int(input())
for tc in range(1, T + 1):
    word = input().strip()
    total = 0
    for ch in word:
        total += ord(ch) - ord("A") + 1
    print(f"#{tc} {total}")
```

## P03. 가장 많은 점수

점수 범위가 0부터 100까지로 작으므로 카운팅 배열이 가장 단순하다. 동점일 때 큰 점수를 고르려면 0부터 100까지 돌면서 `>=`로 갱신하거나, 100부터 내려오며 처음 최댓값을 찾으면 된다.

```python
T = int(input())
for tc in range(1, T + 1):
    N = int(input())
    scores = list(map(int, input().split()))
    count = [0] * 101
    for score in scores:
        count[score] += 1

    best = 0
    for score in range(101):
        if count[score] >= count[best]:
            best = score

    print(f"#{tc} {best}")
```

## P04. 날짜 차이

월별 일수를 누적해 해당 날짜가 1년 중 몇 번째 날인지 구한다. 시작일과 종료일을 모두 포함하므로 차이에 1을 더한다.

```python
days = [0, 31, 28, 31, 30, 31, 30, 31, 31, 30, 31, 30, 31]

def day_of_year(month, day):
    return sum(days[:month]) + day

T = int(input())
for tc in range(1, T + 1):
    m1, d1, m2, d2 = map(int, input().split())
    ans = day_of_year(m2, d2) - day_of_year(m1, d1) + 1
    print(f"#{tc} {ans}")
```

## P05. 카드 뒤집기

N과 Q가 크지 않은 기초 문제라면 명령마다 직접 뒤집어도 된다. 인덱스는 입력이 1부터 시작하므로 Python 리스트에서는 `l - 1`부터 `r - 1`까지 처리한다.

```python
T = int(input())
for tc in range(1, T + 1):
    N, Q = map(int, input().split())
    cards = list(map(int, input().split()))

    for _ in range(Q):
        l, r = map(int, input().split())
        for i in range(l - 1, r):
            cards[i] = 1 - cards[i]

    print(f"#{tc} {sum(cards)}")
```

확장: N과 Q가 매우 크다면 차이 배열이나 누적 XOR을 고려한다. 하지만 D1에서는 직접 구현으로 충분하다.

## P06. 압축 풀기

문자열을 계속 `+=`로 붙여도 작은 입력에서는 괜찮지만, 습관상 리스트에 담고 마지막에 `join()`하는 것이 좋다.

```python
T = int(input())
for tc in range(1, T + 1):
    N = int(input())
    parts = []
    for _ in range(N):
        ch, cnt = input().split()
        parts.append(ch * int(cnt))

    result = "".join(parts)
    print(f"#{tc}")
    for i in range(0, len(result), 10):
        print(result[i:i + 10])
```
