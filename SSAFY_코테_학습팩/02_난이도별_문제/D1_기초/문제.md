# D1 기초 문제

목표: 입력, 반복문, 리스트, 문자열, 카운팅 배열을 실수 없이 작성합니다.

## P01. 홀수 합과 평균

각 테스트케이스마다 숫자 N개가 주어진다. 홀수의 합과 전체 평균을 반올림한 값을 출력하라.

입력:

```text
T
N
a1 a2 ... aN
```

출력:

```text
#tc 홀수합 반올림평균
```

예시:

```text
입력
2
5
1 2 3 4 5
4
10 11 12 13

출력
#1 9 3
#2 24 12
```

## P02. 알파벳 점수 합

대문자로만 이루어진 문자열이 주어진다. `A=1`, `B=2`, ..., `Z=26`이라고 할 때 문자열 점수의 합을 구하라.

입력:

```text
T
WORD
```

예시:

```text
입력
2
ABCZ
SSAFY

출력
#1 32
#2 70
```

## P03. 가장 많은 점수

0 이상 100 이하의 점수 N개가 주어진다. 가장 많이 등장한 점수를 출력하라. 여러 점수가 같은 횟수로 등장하면 더 큰 점수를 출력한다.

입력:

```text
T
N
s1 s2 ... sN
```

예시:

```text
입력
2
6
80 90 80 70 90 90
5
10 20 20 30 30

출력
#1 90
#2 30
```

## P04. 날짜 차이

같은 해의 두 날짜 `m1 d1 m2 d2`가 주어진다. 시작일과 종료일을 모두 포함한 날짜 수를 구하라. 윤년은 고려하지 않는다.

예시:

```text
입력
2
3 1 3 1
3 1 3 5

출력
#1 1
#2 5
```

## P05. 카드 뒤집기

0 또는 1이 적힌 카드 N장이 일렬로 있다. Q개의 명령이 주어지고, 각 명령은 `l r`이다. l번째 카드부터 r번째 카드까지 모두 뒤집는다. 0은 1로, 1은 0으로 바뀐다. 모든 명령 후 1인 카드의 개수를 출력하라.

입력:

```text
T
N Q
c1 c2 ... cN
l1 r1
...
lQ rQ
```

예시:

```text
입력
1
5 2
1 0 0 1 0
2 4
1 5

출력
#1 2
```

## P06. 압축 풀기

문자와 반복 횟수 쌍이 N개 주어진다. 압축을 풀어 만든 문자열을 10글자씩 끊어 출력하라.

입력:

```text
T
N
문자 개수
...
```

출력은 테스트케이스 번호를 먼저 출력하고, 다음 줄부터 10글자씩 출력한다.

예시:

```text
입력
1
3
A 4
B 8
C 3

출력
#1
AAAABBBBBB
BBCCC
```
