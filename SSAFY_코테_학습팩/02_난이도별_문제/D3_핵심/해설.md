## P01. 창고 평탄화

N이 작으면 매 작업마다 정렬해도 충분하다. 가장 낮은 값에 1을 더하고 가장 높은 값에서 1을 뺀 뒤 다시 정렬한다.

```python
T = int(input())
for tc in range(1, T + 1):
    N, D = map(int, input().split())
    heights = list(map(int, input().split()))

    for _ in range(D):
        heights.sort()
        if heights[-1] - heights[0] <= 1:
            break
        heights[0] += 1
        heights[-1] -= 1

    heights.sort()
    print(f"#{tc} {heights[-1] - heights[0]}")
```

## P02. 암호 생성기

앞에서 꺼내고 뒤에 넣는 구조이므로 `deque`를 쓴다. 감소량은 1부터 5까지 반복된다.

```python
from collections import deque

T = int(input())
for tc in range(1, T + 1):
    q = deque(map(int, input().split()))
    dec = 1

    while True:
        x = q.popleft() - dec
        if x <= 0:
            q.append(0)
            break
        q.append(x)
        dec += 1
        if dec == 6:
            dec = 1

    print(f"#{tc}", *q)
```

## P03. 단어 자리 찾기

행과 열을 각각 보면서 연속된 1의 길이를 센다. 0을 만나거나 끝에 도달했을 때 길이가 K이면 답을 1 증가시킨다.

```python
def count_line(line, K):
    count = 0
    length = 0
    for x in line:
        if x == 1:
            length += 1
        else:
            if length == K:
                count += 1
            length = 0
    if length == K:
        count += 1
    return count

T = int(input())
for tc in range(1, T + 1):
    N, K = map(int, input().split())
    board = [list(map(int, input().split())) for _ in range(N)]
    ans = 0

    for r in range(N):
        ans += count_line(board[r], K)

    for c in range(N):
        col = [board[r][c] for r in range(N)]
        ans += count_line(col, K)

    print(f"#{tc} {ans}")
```

## P04. 보물 지도 최단거리

상하좌우 한 칸 이동 비용이 모두 1이므로 BFS가 최단거리를 보장한다. `dist` 배열을 -1로 초기화하고, 시작점만 0으로 둔다.

```python
from collections import deque

dr = [-1, 1, 0, 0]
dc = [0, 0, -1, 1]

T = int(input())
for tc in range(1, T + 1):
    N, M = map(int, input().split())
    board = [list(input().strip()) for _ in range(N)]

    sr = sc = -1
    for r in range(N):
        for c in range(M):
            if board[r][c] == "S":
                sr, sc = r, c

    dist = [[-1] * M for _ in range(N)]
    q = deque([(sr, sc)])
    dist[sr][sc] = 0

    while q:
        r, c = q.popleft()
        for d in range(4):
            nr = r + dr[d]
            nc = c + dc[d]
            if 0 <= nr < N and 0 <= nc < M:
                if dist[nr][nc] == -1 and board[nr][nc] != "#":
                    dist[nr][nc] = dist[r][c] + 1
                    q.append((nr, nc))

    ans = -1
    for r in range(N):
        for c in range(M):
            if board[r][c] == "G":
                ans = dist[r][c]

    print(f"#{tc} {ans}")
```

## P05. 선반 높이 맞추기

각 직원을 선택하거나 선택하지 않는 부분집합 문제다. 합이 B 이상이 되면 더 선택할 필요가 없으므로 바로 답을 갱신하고 가지치기한다.

```python
T = int(input())
for tc in range(1, T + 1):
    N, B = map(int, input().split())
    heights = list(map(int, input().split()))
    ans = [10**9]

    def search(idx, total):
        if total >= B:
            ans[0] = min(ans[0], total - B)
            return
        if idx == N:
            return
        if ans[0] == 0:
            return

        search(idx + 1, total + heights[idx])
        search(idx + 1, total)

    search(0, 0)
    print(f"#{tc} {ans[0]}")
```

실전에서는 함수 전체를 `solve()`로 감싸고 `nonlocal ans`를 써도 된다. 위 코드는 전역이 아닌 환경에서도 동작하게 리스트로 감싼 형태다.

## P06. 문자열 폭발

최근에 남은 문자와 새 문자를 비교해야 하므로 스택이 맞다. 같으면 `pop()`, 다르면 `append()`한다.

```python
T = int(input())
for tc in range(1, T + 1):
    s = input().strip()
    stack = []

    for ch in s:
        if stack and stack[-1] == ch:
            stack.pop()
        else:
            stack.append(ch)

    print(f"#{tc} {len(stack)}")
```
