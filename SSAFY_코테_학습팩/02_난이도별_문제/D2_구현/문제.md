# D2 구현 문제

목표: 2차원 배열, 델타 탐색, 회전, 조건 시뮬레이션을 익힙니다.

## P01. 달팽이 번호판

N x N 배열에 1부터 N²까지 오른쪽, 아래, 왼쪽, 위 순서로 달팽이 모양 숫자를 채워 출력하라.

예시:

```text
입력
1
3

출력
#1
1 2 3
8 9 4
7 6 5
```

## P02. 파리채 최대합

N x N 배열에 파리 수가 적혀 있다. M x M 크기의 파리채를 한 번 내리칠 때 잡을 수 있는 파리 수의 최댓값을 구하라.

예시:

```text
입력
1
4 2
1 3 3 6
2 1 4 2
5 2 1 7
1 3 2 2

출력
#1 15
```

## P03. 숫자 배열 회전

N x N 배열을 90도, 180도, 270도 회전한 결과를 각 행마다 나란히 출력하라. 각 회전 결과는 공백 없이 붙인 문자열로 출력한다.

예시:

```text
입력
1
3
1 2 3
4 5 6
7 8 9

출력
#1
741 987 369
852 654 258
963 321 147
```

## P04. 농장 수확

N x N 농장의 각 칸에 한 자리 수확량이 적혀 있다. N은 홀수다. 중앙을 기준으로 마름모 모양 영역의 수확량 합을 구하라.

예시:

```text
입력
1
5
14054
44250
02032
51204
52212

출력
#1 23
```

## P05. 메모리 복구

처음 메모리는 모두 0이다. 한 번의 작업으로 특정 위치부터 끝까지를 모두 0 또는 모두 1로 바꿀 수 있다. 목표 비트열을 만들기 위한 최소 작업 횟수를 구하라.

예시:

```text
입력
3
0011
0101
1110

출력
#1 1
#2 3
#3 2
```

## P06. 폭탄 확산

N x N 빈 격자에 K개의 폭탄이 순서대로 떨어진다. 폭탄이 떨어지면 해당 칸과 상하좌우 칸의 값이 1씩 증가한다. 격자 밖은 무시한다. 모든 폭탄이 떨어진 뒤 가장 큰 값을 출력하라.

입력의 폭탄 좌표는 1부터 시작한다.

예시:

```text
입력
1
3 2
2 2
1 1

출력
#1 2
```
