## P01. 달팽이 번호판

방향 배열을 오른쪽, 아래, 왼쪽, 위 순서로 두고 다음 칸이 범위를 벗어나거나 이미 숫자가 있으면 방향을 바꾼다.

```python
dr = [0, 1, 0, -1]
dc = [1, 0, -1, 0]

T = int(input())
for tc in range(1, T + 1):
    N = int(input())
    board = [[0] * N for _ in range(N)]
    r = c = d = 0

    for num in range(1, N * N + 1):
        board[r][c] = num
        nr = r + dr[d]
        nc = c + dc[d]
        if nr < 0 or nr >= N or nc < 0 or nc >= N or board[nr][nc] != 0:
            d = (d + 1) % 4
            nr = r + dr[d]
            nc = c + dc[d]
        r, c = nr, nc

    print(f"#{tc}")
    for row in board:
        print(*row)
```

## P02. 파리채 최대합

가능한 왼쪽 위 시작점은 `0 <= r <= N - M`, `0 <= c <= N - M`이다. 각 시작점에서 M x M 합을 구한다.

```python
T = int(input())
for tc in range(1, T + 1):
    N, M = map(int, input().split())
    board = [list(map(int, input().split())) for _ in range(N)]
    ans = 0

    for r in range(N - M + 1):
        for c in range(N - M + 1):
            total = 0
            for i in range(M):
                for j in range(M):
                    total += board[r + i][c + j]
            ans = max(ans, total)

    print(f"#{tc} {ans}")
```

확장: N이 크고 M도 크면 2차원 누적합으로 최적화한다.

## P03. 숫자 배열 회전

시계 방향 90도 회전 공식은 `rotated[c][N - 1 - r] = board[r][c]`이다. 180도와 270도는 90도 회전을 반복해서 만들면 실수가 줄어든다.

```python
def rotate_90(board):
    N = len(board)
    rotated = [[0] * N for _ in range(N)]
    for r in range(N):
        for c in range(N):
            rotated[c][N - 1 - r] = board[r][c]
    return rotated

T = int(input())
for tc in range(1, T + 1):
    N = int(input())
    board = [list(map(int, input().split())) for _ in range(N)]
    r90 = rotate_90(board)
    r180 = rotate_90(r90)
    r270 = rotate_90(r180)

    print(f"#{tc}")
    for i in range(N):
        a = "".join(map(str, r90[i]))
        b = "".join(map(str, r180[i]))
        c = "".join(map(str, r270[i]))
        print(a, b, c)
```

## P04. 농장 수확

중앙 행에서 가장 넓고, 위아래로 갈수록 범위가 줄어든다. 각 행에서 중앙까지의 거리 `dist`를 구하면 시작 열은 `dist`, 끝 열은 `N - dist - 1`이다.

```python
T = int(input())
for tc in range(1, T + 1):
    N = int(input())
    board = [list(map(int, input().strip())) for _ in range(N)]
    mid = N // 2
    total = 0

    for r in range(N):
        dist = abs(mid - r)
        for c in range(dist, N - dist):
            total += board[r][c]

    print(f"#{tc} {total}")
```

## P05. 메모리 복구

처음 상태가 모두 0이므로, 왼쪽부터 보면서 현재 상태와 목표 비트가 달라지는 순간 작업이 1번 필요하다. 이후 현재 상태를 목표 비트로 바꿔서 계속 진행한다.

```python
T = int(input())
for tc in range(1, T + 1):
    target = input().strip()
    current = "0"
    count = 0

    for bit in target:
        if bit != current:
            count += 1
            current = bit

    print(f"#{tc} {count}")
```

## P06. 폭탄 확산

폭탄 한 개가 영향을 주는 방향은 자기 자신 포함 5개다. 좌표가 1부터 시작하므로 입력 직후 1을 빼서 0-index로 바꾼다.

```python
dr = [0, -1, 1, 0, 0]
dc = [0, 0, 0, -1, 1]

T = int(input())
for tc in range(1, T + 1):
    N, K = map(int, input().split())
    board = [[0] * N for _ in range(N)]

    for _ in range(K):
        r, c = map(int, input().split())
        r -= 1
        c -= 1
        for d in range(5):
            nr = r + dr[d]
            nc = c + dc[d]
            if 0 <= nr < N and 0 <= nc < N:
                board[nr][nc] += 1

    ans = max(max(row) for row in board)
    print(f"#{tc} {ans}")
```
