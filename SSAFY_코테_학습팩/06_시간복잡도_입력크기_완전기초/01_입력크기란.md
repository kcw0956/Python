# 01. 입력 크기란?

## 입력 크기의 의미

코딩 테스트 문제에는 보통 이런 조건이 나옵니다.

```text
1 <= N <= 100
1 <= M <= 100
1 <= T <= 10
```

여기서 `N`, `M`, `T`가 바로 입력 크기입니다.

입력 크기는 문제에서 주어지는 데이터의 양입니다. 이 값이 작으면 모든 경우를 다 봐도 되고, 크면 더 똑똑한 방법을 써야 합니다.

## 예시 1: 숫자 N개

```text
N = 5
1 3 5 7 9
```

N은 숫자의 개수입니다.

만약 `N <= 100`이면 숫자 100개입니다. 이 정도는 거의 아무렇게나 훑어도 됩니다.

만약 `N <= 100000`이면 숫자 10만 개입니다. 이때는 이중 반복문을 조심해야 합니다.

## 예시 2: N x N 배열

```text
N = 5
5 x 5 격자
```

N은 5지만, 실제 칸 수는 `N * N = 25`입니다.

만약 `N <= 100`이면 칸 수는 `100 * 100 = 10000`입니다.

이런 문제에서 전체 칸을 한 번 도는 것은 O(N^2)입니다.

```python
for r in range(N):
    for c in range(N):
        pass
```

겉으로는 반복문이 2개라서 무조건 나쁜 것이 아닙니다. N이 100이면 1만 번이라 괜찮습니다.

## 예시 3: N x M 배열

```text
1 <= N <= 100
1 <= M <= 100
```

전체 칸 수는 `N * M`입니다.

최대는 `100 * 100 = 10000`입니다.

따라서 BFS 한 번, DFS 한 번, 전체 칸 순회는 보통 가능합니다.

## 예시 4: 테스트케이스 T

```text
T = 10
N = 1000
```

테스트케이스가 여러 개면 전체 반복 횟수는 `T`까지 곱해서 생각합니다.

```python
for tc in range(T):
    for i in range(N):
        pass
```

위 코드는 대략 `T * N`번 돕니다.

T가 10이고 N이 1000이면 `10 * 1000 = 10000`번입니다.

## 입력 크기를 봐야 하는 이유

같은 문제라도 N의 크기에 따라 가능한 풀이가 달라집니다.

예를 들어 두 숫자의 합이 K가 되는 쌍을 찾는 문제가 있다고 합시다.

### N이 100이면

모든 쌍을 다 봐도 됩니다.

```python
for i in range(N):
    for j in range(i + 1, N):
        if arr[i] + arr[j] == K:
            pass
```

반복 횟수는 대략 `N^2`입니다.

N이 100이면 1만 번 정도라 괜찮습니다.

### N이 100000이면

위 풀이는 대략 `100000 * 100000 = 10000000000`번입니다.

100억 번이라 Python으로는 사실상 불가능합니다.

이때는 정렬, set, 투 포인터 같은 다른 방법을 생각해야 합니다.

## 문제 읽을 때 표시할 것

문제를 읽으면 아래 값을 먼저 찾습니다.

- 테스트케이스 수 `T`
- 배열 길이 `N`
- 격자 크기 `N x M`
- 명령 개수 `Q`
- 선택해야 하는 개수 `K`
- 숫자의 값 범위

그리고 대략 이렇게 계산합니다.

```text
전체 반복 횟수 = T * 내 풀이 반복 횟수
```

## 자주 나오는 입력 크기 해석

| 조건 | 의미 |
|---|---|
| N <= 10 | 순열, 백트래킹 가능할 수 있음 |
| N <= 20 | 부분집합 2^N을 고민할 수 있음 |
| N <= 100 | N^3도 상황에 따라 가능, N^2는 보통 가능 |
| N <= 1000 | N^2는 약 100만 번이라 가능할 때 많음 |
| N <= 100000 | N^2는 불가능, O(N log N) 또는 O(N) 필요 |
| N <= 1000000 | 거의 O(N) 위주 |

## 핵심 정리

입력 크기는 풀이 선택의 신호입니다.

- N이 작다: 모든 경우를 다 보는 풀이 가능
- N이 중간이다: 이중 반복문 가능 여부 확인
- N이 크다: 정렬, 해시, 누적합, DP, 그리디 등을 고려
- 격자다: 전체 칸 수는 `N * M`
- 테스트케이스가 많다: `T`까지 곱해서 생각
