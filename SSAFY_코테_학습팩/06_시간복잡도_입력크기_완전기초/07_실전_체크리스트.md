# 07. 실전 체크리스트

문제를 받으면 코드부터 치지 말고 3분만 이 순서로 판단하세요.

## 1단계: 입력 크기 찾기

아래 값을 표시합니다.

- `T`: 테스트케이스 수
- `N`: 배열 길이, 사람 수, 문제 수
- `M`: 격자 열 수, 추가 크기
- `Q`: 질문 수, 명령 수
- `K`: 선택 개수, 목표 길이

그리고 전체 반복 횟수를 대략 계산합니다.

```text
T * 내 풀이 반복 횟수
```

## 2단계: 문제 유형 찾기

아래 단어를 보면 바로 의심합니다.

| 문제 표현 | 의심할 패턴 |
|---|---|
| 최소 이동 횟수 | BFS |
| 최소 비용 | 다익스트라 또는 DP |
| 구간 합, 여러 질문 | 누적합 |
| 일부 선택 | DFS, 백트래킹, DP |
| 모든 순서 | 순열, 백트래킹 |
| 연결된 영역 | BFS 또는 DFS |
| 가장 큰/작은 것부터 | 정렬, 그리디 |
| N x M 격자 | 델타 탐색 |
| 반복해서 상태 변화 | 시뮬레이션 |

## 3단계: 내 풀이가 가능한지 계산

예:

```text
N = 100000
내 풀이 = 이중 반복문
반복 횟수 = 100000 * 100000 = 100억
결론 = 안 됨
```

예:

```text
N = 100, M = 100
내 풀이 = BFS 한 번
반복 횟수 = 100 * 100 = 1만
결론 = 됨
```

## 4단계: 안 되면 패턴을 바꾸기

| 안 되는 풀이 | 바꿔볼 풀이 |
|---|---|
| 모든 쌍 O(N^2) | set, 정렬, 투 포인터 |
| 매번 구간 합 O(NQ) | 누적합 |
| 모든 경로 무작정 DFS | BFS, DP, 가지치기 |
| 매번 정렬 | 한 번 정렬, heap |
| 모든 시작점에서 BFS | 다중 시작 BFS, 전처리 |

## 5단계: 코드 작성 전 메모

코드 치기 전에 아래처럼 짧게 적습니다.

```text
N <= 100, M <= 100
격자 최단거리
O(NM) BFS 가능
dist 배열 사용
큐에 넣을 때 방문 처리
```

이 4줄을 적고 시작하면 중간에 풀이가 흔들릴 확률이 줄어듭니다.

## 시간복잡도 빠른 암기표

```text
N <= 10       순열/백트래킹 가능
N <= 20       부분집합 가능
N <= 100      N^3 조심해서 가능
N <= 1000     N^2 가능할 때 많음
N <= 100000   N log N 또는 N
N <= 1000000  N 중심
```

## 초심자용 결론

문제를 풀 때 매번 이 질문만 해도 실력이 빨리 늡니다.

1. N이 몇인가?
2. 내 코드는 몇 번 도는가?
3. 1천만 번 근처인가, 훨씬 넘는가?
4. 넘으면 어떤 패턴으로 줄일 수 있는가?

이걸 매 문제마다 반복하면 시간복잡도는 자연스럽게 익숙해집니다.
