# 03. 반복문 복잡도 계산법

시간복잡도는 대부분 반복문을 세면 됩니다.

## 1. 반복문 하나

```python
for i in range(N):
    print(i)
```

N번 실행됩니다.

시간복잡도는 O(N)입니다.

## 2. 반복문 두 개가 따로 있음

```python
for i in range(N):
    pass

for j in range(N):
    pass
```

총 `N + N = 2N`번입니다.

빅오에서는 상수를 버려서 O(N)입니다.

## 3. 이중 반복문

```python
for i in range(N):
    for j in range(N):
        pass
```

바깥 반복 1번마다 안쪽이 N번 돕니다.

총 `N * N = N^2`번입니다.

시간복잡도는 O(N^2)입니다.

## 4. N x M 이중 반복문

```python
for r in range(N):
    for c in range(M):
        pass
```

총 `N * M`번입니다.

시간복잡도는 O(NM)입니다.

격자 문제에서 전체 칸을 한 번 훑으면 O(NM)입니다.

## 5. 삼중 반복문

```python
for i in range(N):
    for j in range(N):
        for k in range(N):
            pass
```

총 `N * N * N = N^3`번입니다.

시간복잡도는 O(N^3)입니다.

## 6. 안쪽 반복 범위가 달라지는 경우

```python
for i in range(N):
    for j in range(i + 1, N):
        pass
```

이 코드는 모든 쌍 `(i, j)`를 한 번씩 봅니다.

반복 횟수는 대략 `N * (N - 1) / 2`입니다.

빅오에서는 O(N^2)입니다.

정확히 반만 돈다고 해도 N^2 계열입니다.

## 7. 반복문 안에 슬라이싱이 있는 경우

```python
for i in range(N):
    part = arr[i:i + K]
```

겉으로는 반복문이 하나지만, 슬라이싱 `arr[i:i + K]`는 K개를 복사합니다.

시간복잡도는 O(NK)입니다.

K가 N에 가까우면 O(N^2)이 될 수 있습니다.

## 8. 반복문 안에 sum이 있는 경우

```python
for i in range(N - K + 1):
    total = sum(arr[i:i + K])
```

`sum()`은 구간 길이 K만큼 돕니다.

따라서 전체는 O(NK)입니다.

이런 경우 구간합을 많이 구한다면 누적합을 써서 O(N + Q)로 줄일 수 있습니다.

## 9. while문

```python
while N > 0:
    N -= 1
```

N번 돕니다.

O(N)입니다.

```python
while N > 0:
    N //= 2
```

매번 절반으로 줄어듭니다.

O(log N)입니다.

## 10. BFS/DFS 복잡도

격자 BFS:

```python
while q:
    r, c = q.popleft()
    for d in range(4):
        ...
```

각 칸을 한 번 방문하고, 각 칸에서 4방향을 봅니다.

전체 칸 수가 `N * M`이면 시간복잡도는 O(NM)입니다.

`4 * N * M`이지만 4는 상수라서 버립니다.

## 11. 정렬

```python
arr.sort()
```

정렬은 보통 O(N log N)입니다.

정렬 후 한 번 훑으면:

```python
arr.sort()
for x in arr:
    pass
```

O(N log N + N)입니다.

큰 항만 남기면 O(N log N)입니다.

## 12. 재귀에서 가지가 2개

```python
def dfs(idx):
    if idx == N:
        return
    dfs(idx + 1)
    dfs(idx + 1)
```

각 단계마다 선택지가 2개입니다.

시간복잡도는 O(2^N)입니다.

부분집합 문제에서 많이 나옵니다.

## 13. 재귀에서 순열

```python
def perm(depth):
    if depth == N:
        return
    for i in range(N):
        if not used[i]:
            used[i] = True
            perm(depth + 1)
            used[i] = False
```

처음에는 N개, 다음에는 N-1개, 다음에는 N-2개를 고릅니다.

시간복잡도는 O(N!)입니다.

## 계산 연습

### 코드 A

```python
for i in range(N):
    for j in range(10):
        pass
```

정답: O(N)

이유: 안쪽 10은 고정 상수입니다.

### 코드 B

```python
for i in range(N):
    for j in range(M):
        pass
```

정답: O(NM)

### 코드 C

```python
for i in range(N):
    arr.sort()
```

정답: O(N^2 log N)

이유: 정렬 O(N log N)을 N번 반복합니다. 이런 코드는 매우 위험합니다.

### 코드 D

```python
for i in range(N):
    for j in range(i):
        pass
```

정답: O(N^2)

이유: 대략 `1 + 2 + 3 + ... + N = N(N+1)/2`입니다.

## 핵심 정리

- 반복문이 따로 있으면 더한다.
- 반복문이 겹쳐 있으면 곱한다.
- 반복문 안의 `sum`, `count`, 슬라이싱, 정렬도 비용이 있다.
- BFS/DFS는 보통 방문하는 상태 수를 센다.
- 재귀는 선택지 개수와 깊이를 본다.
