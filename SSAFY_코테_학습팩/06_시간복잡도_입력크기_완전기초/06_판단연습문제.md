# 06. 판단 연습 문제

이 파일은 코드를 바로 짜는 문제가 아닙니다. 입력 크기를 보고 어떤 풀이가 가능한지 판단하는 연습입니다.

각 문제마다 아래 3가지를 먼저 적어보세요.

1. 가능한 시간복잡도
2. 쓰면 안 되는 풀이
3. 의심할 알고리즘 패턴

## 문제 1

숫자 N개가 주어진다. 모든 숫자의 합을 구하라.

```text
1 <= N <= 100000
```

### 판단

- 가능한 풀이: O(N)
- 쓰면 안 되는 풀이: 굳이 정렬 O(N log N)을 할 필요 없음
- 패턴: 단순 순회

### 이유

숫자 N개를 한 번씩 보면 충분합니다.

## 문제 2

숫자 N개 중 두 수를 골라 합이 K가 되는 쌍이 있는지 확인하라.

```text
1 <= N <= 100
```

### 판단

- 가능한 풀이: O(N^2)
- 패턴: 모든 쌍 완전탐색

### 이유

N이 100이면 모든 쌍은 약 1만 개입니다. 충분히 가능합니다.

## 문제 3

숫자 N개 중 두 수를 골라 합이 K가 되는 쌍이 있는지 확인하라.

```text
1 <= N <= 100000
```

### 판단

- 가능한 풀이: O(N), O(N log N)
- 쓰면 안 되는 풀이: O(N^2)
- 패턴: set 또는 정렬 + 투 포인터

### 이유

모든 쌍은 100억 번이라 불가능합니다.

set을 쓰면 각 숫자 x에 대해 K - x가 이미 있었는지 확인할 수 있습니다.

## 문제 4

N x M 격자에서 시작점 S부터 도착점 G까지 최소 이동 횟수를 구하라. 벽은 지나갈 수 없다.

```text
1 <= N, M <= 100
```

### 판단

- 가능한 풀이: O(NM)
- 패턴: BFS

### 이유

최소 이동 횟수이고, 한 칸 이동 비용이 모두 1입니다. BFS입니다.

## 문제 5

N개의 수가 있고 Q개의 질문이 있다. 각 질문은 `l r`이고, l번째부터 r번째까지의 합을 출력하라.

```text
1 <= N <= 100000
1 <= Q <= 100000
```

### 판단

- 가능한 풀이: O(N + Q)
- 쓰면 안 되는 풀이: 질문마다 sum으로 O(NQ)
- 패턴: 누적합

### 이유

매 질문마다 직접 더하면 최악의 경우 100억 번입니다. 누적합을 만들면 질문마다 O(1)에 답할 수 있습니다.

## 문제 6

N명의 키가 주어진다. 일부를 골라 키 합이 B 이상이 되게 할 때, B와의 차이를 최소로 하라.

```text
1 <= N <= 20
```

### 판단

- 가능한 풀이: O(2^N)
- 패턴: 부분집합 DFS, 백트래킹

### 이유

각 사람을 고르거나 안 고르는 경우가 있습니다. N이 20이면 약 100만 가지라 가능할 수 있습니다.

## 문제 7

N개의 도시를 모두 한 번씩 방문하는 최소 비용을 구하라.

```text
1 <= N <= 10
```

### 판단

- 가능한 풀이: 순열/백트래킹
- 패턴: O(N!)에 가지치기

### 이유

방문 순서를 모두 시도해야 할 수 있습니다. N이 10이면 10!이 크긴 하지만, 조건에 따라 백트래킹으로 풀 수 있습니다.

## 문제 8

N x N 격자의 각 칸에 비용이 있다. 왼쪽 위에서 오른쪽 아래까지 이동할 때 최소 비용을 구하라. 상하좌우 이동 가능.

```text
1 <= N <= 100
각 칸 비용은 0 이상 9 이하
```

### 판단

- 가능한 풀이: 다익스트라
- BFS만 쓰면 위험
- 패턴: 가중치 최단거리

### 이유

칸마다 비용이 다르므로 이동 횟수 최소가 아니라 비용 최소입니다.

## 문제 9

N x N 배열에서 M x M 부분 격자 합의 최댓값을 구하라.

```text
1 <= N <= 30
1 <= M <= N
```

### 판단

- 가능한 풀이: 직접 합산 O(N^2 M^2)
- 패턴: 구현

### 이유

N이 30이면 최악에도 `30^2 * 30^2 = 810000` 정도입니다. 직접 합산도 가능합니다.

단, N이 1000이면 누적합을 생각해야 합니다.

## 문제 10

N x N 배열에서 M x M 부분 격자 합의 최댓값을 구하라.

```text
1 <= N <= 1000
1 <= M <= N
```

### 판단

- 가능한 풀이: 2차원 누적합 O(N^2)
- 쓰면 안 되는 풀이: 모든 시작점마다 M x M 직접 합산
- 패턴: 2차원 누적합

### 이유

직접 합산은 최악에 O(N^2 M^2)라 너무 큽니다. 2차원 누적합으로 각 사각형 합을 O(1)에 구해야 합니다.
