# 02. 시간복잡도와 빅오

## 시간복잡도란?

시간복잡도는 코드가 입력 크기에 따라 얼마나 오래 걸리는지 표현하는 방법입니다.

정확히 몇 초 걸리는지를 말하는 것이 아닙니다. 입력이 커질 때 반복 횟수가 어떤 모양으로 커지는지를 말합니다.

예를 들어 숫자 N개를 한 번 훑는 코드는 N이 커질수록 반복 횟수도 N만큼 늘어납니다.

```python
for i in range(N):
    pass
```

이 코드는 O(N)이라고 합니다.

## 빅오란?

빅오 표기법은 대략적인 증가 속도를 나타냅니다.

```text
O(1)
O(log N)
O(N)
O(N log N)
O(N^2)
O(N^3)
O(2^N)
O(N!)
```

중요한 것은 정확한 연산 횟수가 아니라, 입력이 커질 때 얼마나 빠르게 터지는지입니다.

## O(1): 입력 크기와 상관없이 일정

```python
print(arr[0])
```

N이 10이든 100만이든 한 번만 접근합니다.

리스트 인덱스 접근, 변수 비교, 딕셔너리 평균 접근은 보통 O(1)로 봅니다.

## O(N): 입력을 한 번 훑음

```python
total = 0
for x in arr:
    total += x
```

N개를 한 번 봅니다.

N이 100000이면 10만 번 정도입니다. 보통 매우 좋습니다.

## O(N^2): 이중 반복문

```python
for i in range(N):
    for j in range(N):
        pass
```

N이 100이면 1만 번입니다.

N이 1000이면 100만 번입니다.

N이 100000이면 100억 번입니다.

그래서 O(N^2)은 N이 작거나 중간일 때만 가능합니다.

## O(N^3): 삼중 반복문

```python
for i in range(N):
    for j in range(N):
        for k in range(N):
            pass
```

N이 100이면 100만 번입니다.

N이 1000이면 10억 번입니다.

삼중 반복문은 N이 100 정도만 되어도 조심해야 합니다.

## O(log N): 반씩 줄어듦

대표 예시는 이진 탐색입니다.

```python
left = 0
right = N - 1

while left <= right:
    mid = (left + right) // 2
    if arr[mid] < target:
        left = mid + 1
    else:
        right = mid - 1
```

N이 100만이어도 약 20번 정도만 비교합니다.

`log N`은 매우 빠릅니다.

## O(N log N): 정렬

Python의 `sort()`와 `sorted()`는 보통 O(N log N)입니다.

```python
arr.sort()
```

N이 100000이어도 정렬은 보통 가능합니다.

그래서 N이 클 때는 `정렬 후 처리`가 자주 나옵니다.

## O(2^N): 부분집합

N개 각각을 고르거나 안 고르는 경우입니다.

```python
def dfs(idx):
    if idx == N:
        return
    dfs(idx + 1)  # 선택
    dfs(idx + 1)  # 미선택
```

N이 20이면 약 100만 가지입니다.

N이 30이면 약 10억 가지입니다.

부분집합 풀이는 보통 N이 20 안팎일 때만 생각합니다.

## O(N!): 순열

N개를 순서대로 나열하는 경우입니다.

```python
from itertools import permutations

for case in permutations(arr):
    pass
```

N이 10이면 362만 가지입니다.

N이 11이면 3991만 가지입니다.

N이 12면 4억 7900만 가지입니다.

순열은 N이 조금만 커져도 위험합니다.

## 상수는 보통 버린다

아래 코드는 정확히는 2N번 돕니다.

```python
for i in range(N):
    pass

for i in range(N):
    pass
```

하지만 시간복잡도는 O(N)이라고 씁니다.

왜냐하면 입력이 커질 때 중요한 것은 `2`가 아니라 `N에 비례해서 증가한다`는 사실이기 때문입니다.

## 낮은 차수는 보통 버린다

```python
for i in range(N):
    pass

for i in range(N):
    for j in range(N):
        pass
```

전체는 `N + N^2`입니다.

시간복잡도는 O(N^2)이라고 씁니다.

N이 커질수록 N보다 N^2이 훨씬 커지기 때문입니다.

## 시간복잡도 빠른 순서

빠른 순서:

```text
O(1)
O(log N)
O(N)
O(N log N)
O(N^2)
O(N^3)
O(2^N)
O(N!)
```

## 핵심 정리

- 시간복잡도는 입력이 커질 때 코드 반복 횟수가 커지는 모양이다.
- O(N)은 한 번 훑는 것이다.
- O(N^2)은 모든 쌍을 보는 느낌이다.
- O(2^N)은 선택/미선택 부분집합이다.
- O(N!)은 순열이다.
- 입력 크기를 보고 가능한 복잡도를 먼저 정해야 한다.
