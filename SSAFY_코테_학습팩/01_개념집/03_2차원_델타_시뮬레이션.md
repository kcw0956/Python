# 2차원 배열, 델타 탐색, 시뮬레이션

## 1. 2차원 배열은 '행 리스트들을 담은 리스트'

```python
board = [
    [10, 11, 12, 13],
    [20, 21, 22, 23],
    [30, 31, 32, 33],
]
```

`board`는 격자 전체를 담는 변수입니다. 파이썬이 정한 이름은 아닙니다. 가로로 놓인 한 줄이 **행(row)**이고, 같은 세로줄이 **열(column)**입니다.

```text
              열 번호 c
             0   1   2   3
행 번호 r  0  10  11  12  13
           1  20  21  22  23
           2  30  31  32  33
```

```python
print(board[1])     # [20, 21, 22, 23]: 두 번째 행 전체
print(board[1][2])  # 22: 그 행의 세 번째 요소
```

`board[r][c]`는 먼저 r번 행을 고르고, 그 안에서 c번 열을 고릅니다. 첫 번째 행·열의 번호는 0입니다. `(r, c)`는 좌표 두 개를 묶은 튜플입니다.

## 2. N, M, r, c의 차이: 개수와 위치

이 장에서는 모든 격자를 '행 수 N, 열 수 M'으로 표현합니다. 문제에 따라 N과 M의 뜻이 반대일 수도 있으므로 실제 입력 설명을 먼저 확인합니다.

| 변수 | 이름의 의미 | 무엇을 저장하는가 | 위 격자의 예 |
|---|---|---|---|
| `N` | 크기를 표현하는 관례적 이름 | 전체 행 개수 | 3 |
| `M` | 또 다른 크기를 표현하는 관례적 이름 | 전체 열 개수 | 4 |
| `r` | row | 현재 행의 인덱스 | 0, 1, 2 중 하나 |
| `c` | column | 현재 열의 인덱스 | 0, 1, 2, 3 중 하나 |
| `nr` | next row | 이동을 시도할 다음 행 인덱스 | 범위 밖일 수도 있음 |
| `nc` | next column | 이동을 시도할 다음 열 인덱스 | 범위 밖일 수도 있음 |
| `dr` | delta row | 방향별 행 변화량을 담은 리스트 | [-1, 1, 0, 0] |
| `dc` | delta column | 방향별 열 변화량을 담은 리스트 | [0, 0, -1, 1] |
| `d` | direction | 현재 방향을 고르는 인덱스 | 상하좌우라면 0~3 |

`N`, `M`은 마지막 인덱스가 아닙니다. 행이 3개이면 마지막 행 인덱스는 2입니다.

앞 절의 `board`가 있을 때:

```python
N = len(board)     # 행 리스트가 3개이므로 3
M = len(board[0])  # 첫 행의 요소가 4개이므로 4
r = 1
c = 2
print(N, M, r, c, board[r][c])  # 3 4 1 2 22
```

`len(board[0])`은 행이 적어도 하나 있어야 사용할 수 있습니다. 이 장은 모든 행의 길이가 같은 직사각형 격자를 가정합니다. `r`을 늘리면 아래쪽 행으로, `c`를 늘리면 오른쪽 열로 갑니다. 수학 좌표에서 y축이 위로 커지는 그림과 혼동하지 마세요.

## 3. 격자 입력을 읽는 방법

### 공백으로 구분한 숫자

입력:

```text
3 4
10 11 12 13
20 21 22 23
30 31 32 33
```

```python
N, M = map(int, input().split())
board = []
for _ in range(N):
    row = list(map(int, input().split()))
    board.append(row)
print(board[1][2])  # 22
```

`N`줄을 읽고 각 줄의 숫자 `M`개를 한 행에 저장합니다. `_`는 반복 번호를 쓰지 않는다는 관례적 이름, `row`는 방금 읽은 한 행입니다. `map(int, ...)`는 각 문자열을 정수로 바꿉니다.

반복 부분의 축약형은 다음과 같습니다. 위 코드와 둘 중 한 방법만 사용합니다.

```python
board = [list(map(int, input().split())) for _ in range(N)]
```

정사각형 문제에서 한 줄에 `N`만 주어진다면, `N = int(input())`으로 읽고 `M = N`으로 둘 수 있습니다. 직사각형 문제의 `N M`을 `int(input())`으로 읽으면 안 됩니다.

### 공백 없이 붙어 있는 숫자 또는 문자

`123`을 `[1, 2, 3]`으로 읽고 싶다면:

```python
row = list(map(int, "123"))
print(row)  # [1, 2, 3]
```

실제 입력 줄에는 `list(map(int, input().strip()))`을 사용합니다. 각 숫자가 한 자리일 때만 맞는 방식입니다. 공백 구분 입력과 혼동하지 마세요.

`ABC` 같은 문자 행은 `list(input().strip())`으로 읽으면 `['A', 'B', 'C']`가 됩니다. 다만 양끝 공백도 격자의 데이터라면 `.strip()`을 사용하면 안 됩니다.

## 4. 모든 칸을 한 번씩 보기

```python
board = [[1, 2, 3], [4, 5, 6]]
N = len(board)
M = len(board[0])
total = 0
for r in range(N):
    for c in range(M):
        total += board[r][c]
print(total)  # 21
```

바깥 반복에서 행을 고르고, 안쪽 반복에서 그 행의 열을 전부 봅니다.

```text
(r, c)의 순서:
(0, 0) → (0, 1) → (0, 2) → (1, 0) → (1, 1) → (1, 2)
```

`total`은 지금까지 읽은 값의 합입니다. N행 M열의 모든 칸을 한 번씩 보므로 시간복잡도는 `O(N × M)`입니다.

## 5. 델타는 '현재 위치에 더할 변화량'

현재 `(r, c)`가 `(1, 2)`라고 가정합니다. 상하좌우로 한 칸 이동할 때:

| d | 방향 | dr[d] | dc[d] | 계산한 다음 위치 |
|---:|---|---:|---:|---|
| 0 | 위 | -1 | 0 | (0, 2) |
| 1 | 아래 | 1 | 0 | (2, 2) |
| 2 | 왼쪽 | 0 | -1 | (1, 1) |
| 3 | 오른쪽 | 0 | 1 | (1, 3) |

이 표를 두 리스트로 옮긴 것이 델타 배열입니다. `dr[d]`와 `dc[d]`는 반드시 같은 방향의 변화량끼리 짝지어야 합니다.

```python
board = [
    [10, 11, 12, 13],
    [20, 21, 22, 23],
    [30, 31, 32, 33],
]
N = len(board)
M = len(board[0])
r, c = 1, 2

dr = [-1, 1, 0, 0]
dc = [0, 0, -1, 1]

for d in range(4):
    nr = r + dr[d]
    nc = c + dc[d]
    if 0 <= nr < N and 0 <= nc < M:
        print(nr, nc, board[nr][nc])
```

출력:

```text
0 2 12
2 2 32
1 1 21
1 3 23
```

첫 반복 `d = 0`에서는 `nr = 1 + (-1) = 0`, `nc = 2 + 0 = 2`입니다. `nr`, `nc`를 계산했다고 현재 위치 `r`, `c`가 바뀌는 것은 아닙니다. 이 예시는 현재 칸의 이웃 네 칸을 확인할 뿐입니다. 실제로 이동하려면 별도로 `r, c = nr, nc`를 실행해야 합니다.

### 왜 범위를 먼저 검사할까?

`0 <= nr < N`은 '행이 0 이상이고 N 미만', `0 <= nc < M`은 '열이 0 이상이고 M 미만'이라는 뜻입니다. 둘 다 참일 때만 접근합니다.

- 위쪽 가장자리에서 위로 가면 `nr = -1`입니다. 파이썬의 `board[-1]`은 오류가 아니라 마지막 행이므로, 범위 검사 없이 쓰면 엉뚱한 칸을 읽습니다.
- 아래쪽 끝에서 아래로 가면 `nr = N`입니다. 이 인덱스는 존재하지 않으므로 오류입니다.
- 반드시 좌표 계산 → 범위 검사 → 배열 접근 순서로 작성합니다.

## 6. 8방향과 여러 칸 이동

8방향은 대각선을 포함합니다. 다음 순서로 짝지었습니다.

```text
왼쪽 위, 위, 오른쪽 위, 왼쪽, 오른쪽, 왼쪽 아래, 아래, 오른쪽 아래
```

```python
dr = [-1, -1, -1, 0, 0, 1, 1, 1]
dc = [-1, 0, 1, -1, 1, -1, 0, 1]
```

네 방향 예시의 델타를 위 값으로 바꾸고 반복도 `range(8)`로 바꿉니다. 자기 자신인 변화량 `(0, 0)`은 포함하지 않았습니다.

한 방향으로 k칸 떨어진 좌표는 `nr = r + dr[d] * k`, `nc = c + dc[d] * k`입니다. 예를 들어 위쪽으로 두 칸이면 `d = 0`, `k = 2`이므로 행에서 2를 뺍니다. 여기서 `k`는 거리입니다. 중간에 벽이 있으면 멈춰야 하는 문제는 1칸, 2칸, 3칸 순서로 중간 칸도 검사해야 합니다.


## 7. 2차원 배열 만들기: 행을 공유하면 안 됨

```python
N, M = 2, 3
board = [[0] * M for _ in range(N)]
board[0][0] = 9
print(board)  # [[9, 0, 0], [0, 0, 0]]
```

`[0] * M`이라는 새로운 행을 N번 만들어 담습니다. 각 행이 독립적인 리스트입니다.

반면 다음 코드는 같은 행 하나를 여러 번 가리킵니다.

```python
N, M = 2, 3
wrong = [[0] * M] * N
wrong[0][0] = 9
print(wrong)  # [[9, 0, 0], [9, 0, 0]]
```

첫 행만 바꾸려 했는데 다른 행도 바뀝니다. 격자는 첫 번째 방식으로 생성하세요.

## 8. 시계 방향 90도 회전

원본이 N행 M열이면 회전 결과는 M행 N열입니다. 이 절은 정사각형뿐 아니라 직사각형에도 적용됩니다.

```python
board = [[1, 2, 3], [4, 5, 6]]
N = len(board)
M = len(board[0])
rotated = [[0] * N for _ in range(M)]

for r in range(N):
    for c in range(M):
        rotated[c][N - 1 - r] = board[r][c]

for row in rotated:
    print(row)
```

출력:

```text
[4, 1]
[5, 2]
[6, 3]
```

`rotated`는 회전 결과를 담는 새 격자입니다. `row`는 출력할 때 꺼낸 한 행입니다.

좌표 공식은 원본 `(r, c)` → 결과 `(c, N - 1 - r)`입니다.

- 원본 열 c가 결과의 행이 됩니다.
- 원본의 위쪽 행일수록 결과에서는 오른쪽 열로 가야 합니다.
- 원본 행 번호 `0~N-1`을 거꾸로 바꾸면 `N-1-r`입니다.

예를 들어 값 1의 원본 위치는 `(0, 0)`입니다. 결과 위치는 `(0, 2-1-0) = (0, 1)`입니다. 값 4는 `(1, 0)`에서 `(0, 0)`으로 갑니다.

정사각형이면 `M = N`이므로 결과를 만드는 코드는 `[[0] * N for _ in range(N)]`이 됩니다.

### 축약형은 원리를 이해한 뒤 보기

```python
board = [[1, 2, 3], [4, 5, 6]]
rotated = [list(row) for row in zip(*board[::-1])]
print(rotated)  # [[4, 1], [5, 2], [6, 3]]
```

1. `board[::-1]`은 행 순서를 뒤집어 `[[4, 5, 6], [1, 2, 3]]`으로 만듭니다.
2. `*`는 두 행을 별도 인수로 펼칩니다. `zip([4, 5, 6], [1, 2, 3])`을 호출하는 셈입니다.
3. `zip`은 같은 위치끼리 묶어 `(4, 1)`, `(5, 2)`, `(6, 3)`을 제공합니다.
4. `row`는 여기서는 zip이 만든 튜플입니다. `list(row)`로 각 튜플을 행 리스트로 바꿉니다.

처음에는 직접 인덱스를 쓰는 코드를 우선 익힙니다.

## 9. 달팽이 배열: 진행 방향을 상태로 저장

N×N 격자에 1부터 N²까지 오른쪽 → 아래 → 왼쪽 → 위 순서로 채웁니다. 이 절에서는 이 순서에 맞게 델타를 다시 정의합니다. 앞의 '위, 아래, 왼쪽, 오른쪽' 순서와 다릅니다.

| d | 방향 | dr[d] | dc[d] |
|---:|---|---:|---:|
| 0 | 오른쪽 | 0 | 1 |
| 1 | 아래 | 1 | 0 |
| 2 | 왼쪽 | 0 | -1 |
| 3 | 위 | -1 | 0 |

```python
N = 3
board = [[0] * N for _ in range(N)]
dr = [0, 1, 0, -1]
dc = [1, 0, -1, 0]
r = 0
c = 0
d = 0

for num in range(1, N * N + 1):
    board[r][c] = num
    if num == N * N:
        break

    nr = r + dr[d]
    nc = c + dc[d]
    if (nr < 0 or nr >= N or nc < 0 or nc >= N
            or board[nr][nc] != 0):
        d = (d + 1) % 4
        nr = r + dr[d]
        nc = c + dc[d]

    r, c = nr, nc

for row in board:
    print(row)
```

출력:

```text
[1, 2, 3]
[8, 9, 4]
[7, 6, 5]
```

- `num`은 지금 기록할 숫자입니다. `1~N²`를 차례로 사용합니다.
- `board`의 0은 아직 채우지 않았다는 표시입니다.
- `r`, `c`는 현재 위치이며 `(0, 0)`에서 시작합니다.
- `d`는 현재 방향입니다. 0인 오른쪽부터 시작합니다.
- `nr`, `nc`는 현재 방향으로 한 칸 더 가 본 후보 위치입니다.
- 후보가 범위 밖이거나 이미 채운 칸이면 방향을 바꾸고 후보를 다시 계산합니다.
- `r, c = nr, nc`에서 실제 위치를 갱신합니다.
- 마지막 숫자까지 썼으면 `break`로 반복을 끝냅니다. 더 이동할 필요가 없습니다.

`%`는 나머지 연산입니다. `(d + 1) % 4`는 `0 → 1 → 2 → 3 → 0`으로 방향을 순환시킵니다. 이 빈 정사각형을 나선형으로 채우는 조건에서는 막혔을 때 한 번 회전하면 다음 빈 칸을 찾을 수 있습니다. 임의의 벽이 있는 격자에서는 같은 보장이 없습니다.

조건의 `or`는 왼쪽에서 오른쪽으로 평가하다 하나라도 참이면 뒤를 확인하지 않습니다. 따라서 범위 밖일 때 마지막 `board[nr][nc]`에 접근하지 않습니다. 배열 접근 조건을 맨 앞으로 옮기면 안 됩니다.

N=3일 때 처음 세 숫자는 `(0,0)`, `(0,1)`, `(0,2)`에 들어갑니다. 다음 후보 `(0,3)`은 범위 밖이므로 `d`를 1로 바꿔 아래쪽 `(1,2)`로 갑니다.

## 10. 마름모 영역의 합

여기서는 N이 양의 홀수인 N×N 격자에서, 가운데를 기준으로 한 마름모를 선택합니다. N=5이면 선택 모양은 다음과 같습니다. `X`는 선택, `.`은 제외입니다.

```text
..X..
.XXX.
XXXXX
.XXX.
..X..
```

```python
N = 5
board = [[1] * N for _ in range(N)]
mid = N // 2
total = 0
for r in range(N):
    dist = abs(mid - r)
    start = dist
    end = N - dist
    for c in range(start, end):
        total += board[r][c]
print(total)  # 13
```

| 변수 | 의미 |
|---|---|
| `mid` | 가운데 행의 인덱스. 5 // 2 = 2 |
| `r` | 현재 검사하는 행 |
| `dist` | 현재 행과 가운데 행의 거리 |
| `start` | 이 행에서 선택할 첫 열 인덱스. 포함 |
| `end` | 선택 범위 바로 다음 열 인덱스. 제외 |
| `c` | 선택 범위 안에서 움직이는 열 인덱스 |
| `total` | 선택한 칸의 값의 합 |

`//`는 몫을 아래쪽 정수로 내리는 나눗셈이고, `abs`는 절댓값입니다. `abs(2 - 4)`는 2입니다.

| r | dist = abs(2-r) | start | end | 선택 열 | 칸 수 |
|---:|---:|---:|---:|---|---:|
| 0 | 2 | 2 | 3 | 2 | 1 |
| 1 | 1 | 1 | 4 | 1, 2, 3 | 3 |
| 2 | 0 | 0 | 5 | 0, 1, 2, 3, 4 | 5 |
| 3 | 1 | 1 | 4 | 1, 2, 3 | 3 |
| 4 | 2 | 2 | 3 | 2 | 1 |

위쪽과 아래쪽에서 각각 `dist`개만큼 양옆 열을 제외하는 원리입니다. 예시는 모든 값이 1이므로 선택 칸 수 `1+3+5+3+1 = 13`이 합계가 됩니다. 실제 문제에서는 입력받은 board의 값을 합산합니다.

## 11. 시뮬레이션: 규칙대로 상태를 갱신

시뮬레이션은 특별한 함수 이름이 아니라, 문제의 시간·이동·변화 규칙을 코드로 따라가는 풀이 방식입니다. 상태는 현재 위치, 방향, 격자 내용처럼 다음 행동을 결정하는 정보입니다.

먼저 다음을 정합니다.

1. 한 턴에서 무엇을 읽고 무엇을 바꾸는가?
2. 모든 칸이 이전 턴을 보고 동시에 바뀌는가?
3. 앞에서 바뀐 결과를 뒤의 칸이 즉시 참고하는가?
4. 몇 턴 후 또는 어떤 조건에서 끝나는가?

### 동시에 퍼지는 예시: 읽는 격자와 쓰는 격자를 분리

규칙: 1은 퍼지는 상태, 0은 빈 칸입니다. 매 턴 시작할 때 1인 칸이 상하좌우의 0에 퍼집니다. 이번 턴에 새로 바뀐 칸은 다음 턴부터 퍼질 수 있습니다. 한 턴만 실행해 봅니다.

```python
board = [[1, 0, 0, 0]]
N = len(board)
M = len(board[0])
dr = [-1, 1, 0, 0]
dc = [0, 0, -1, 1]
next_board = [row[:] for row in board]

for r in range(N):
    for c in range(M):
        if board[r][c] != 1:
            continue
        for d in range(4):
            nr = r + dr[d]
            nc = c + dc[d]
            if 0 <= nr < N and 0 <= nc < M:
                if board[nr][nc] == 0:
                    next_board[nr][nc] = 1

board = next_board
print(board)  # [[1, 1, 0, 0]]
```

- `board`는 이번 턴 시작 상태입니다. 판단할 때만 읽습니다.
- `next_board`는 다음 턴 상태입니다. 각 행을 복사해 준비하고 여기에만 씁니다.
- `row[:]`은 한 행을 새 리스트로 복사합니다. `next_board = board`는 복사가 아닙니다.
- `continue`는 현재 반복의 나머지를 건너뛰고 다음 c로 넘어갑니다. 현재 칸이 1이 아니면 퍼뜨릴 필요가 없기 때문입니다.
- 모든 칸을 확인한 뒤 `board = next_board`로 다음 상태를 채택합니다.

원본 board를 직접 바꾸면, 왼쪽에서 오른쪽으로 검사하는 동안 새로 1이 된 칸까지 즉시 퍼져 한 턴에 `[[1, 1, 1, 1]]`이 될 수 있습니다. 이는 '동시 변화' 규칙과 다릅니다. 여러 턴을 반복할 때도 매 턴 시작에 next_board를 새로 만들어야 합니다.

## 12. 직접 설명할 수 있는지 확인

- N=3, M=4에서 `(r,c) = (3,0)`은 왜 범위 밖인가? → 행 인덱스는 0~2이기 때문입니다.
- 위로 갈 때 왜 r에서 1을 빼는가? → 작은 행 번호가 위에 있기 때문입니다.
- nr, nc를 계산한 순간 이동한 것인가? → 아닙니다. r, c에 대입해야 현재 위치가 바뀝니다.
- 2×3 격자를 90도 돌리면 몇 행 몇 열인가? → 3행 2열입니다.
- 동시 변화에서 board 대신 next_board를 쓰는 이유는? → 같은 턴의 판단이 모두 이전 상태를 보도록 하기 위해서입니다.
