# 배열, 문자열, 카운팅

## 1. 리스트, 튜플, 딕셔너리부터 구분하기

파이썬 코딩 테스트에서 '배열'이라고 부르는 것은 대개 `list`입니다. C++의 고정 배열과 동일한 타입이라는 뜻은 아닙니다.

```python
arr = [10, 20, 30]       # 리스트: 요소 변경 가능
point = (10, 20)        # 튜플: 요소 교체 불가
scores = {"민수": 90}   # 딕셔너리: 키로 값 조회
```

| 대상 | 값을 읽는 방법 | 특징 |
|---|---|---|
| 리스트 | `arr[0]` → `10` | 순서·인덱스가 있고, 추가·삭제·교체 가능 |
| 튜플 | `point[0]` → `10` | 순서·인덱스가 있고, 요소 교체 불가 |
| 딕셔너리 | `scores["민수"]` → `90` | key-value 쌍 저장. C++의 map 계열과 목적이 비슷함 |

튜플은 파이썬만의 개념은 아닙니다. C++에도 `std::tuple`이 있지만, 파이썬 튜플과 달리 요소 수정이 가능합니다. 튜플은 스택처럼 마지막 값을 먼저 꺼내는 규칙을 가진 자료구조가 아닙니다.

```python
ex = 1, 2, 3       # 쉼표로 나열했으므로 튜플
print(ex)          # (1, 2, 3)
print(type(ex))    # <class 'tuple'>
one = (1,)         # 한 요소 튜플에는 쉼표 필요. (1)은 정수
mixed = [1, "hi", str]
print(mixed)       # [1, 'hi', <class 'str'>]
```

`str`은 문자열 타입 자체입니다. `"str"`이라는 문자열과 다릅니다. 타입도 리스트와 튜플에 저장할 수 있습니다. `type(str)`의 설명은 1장 1절에 있습니다.

튜플의 '변경 불가'는 각 자리에 들어 있는 대상을 교체할 수 없다는 뜻입니다. 튜플 안에 리스트가 있으면 그 리스트의 내용은 변경될 수 있습니다.

```python
data = ([10, 20], "hi")
data[0].append(30)
print(data)  # ([10, 20, 30], 'hi')
```

## 2. 리스트 읽기와 변경

```python
arr = [10, 20, 30]
print(arr[0])   # 10: 인덱스는 0부터
print(arr[-1])  # 30: 음수 인덱스는 뒤에서부터
print(len(arr)) # 3: len은 요소 개수

arr[1] = 99     # 두 번째 요소 교체
arr.append(40)  # 끝에 추가
print(arr)      # [10, 99, 30, 40]

last = arr.pop() # 마지막 요소를 제거하고 그 값을 반환
print(last)      # 40
print(arr)       # [10, 99, 30]
```

`.append()`로 넣고 `.pop()`으로 꺼내면 마지막에 넣은 값이 먼저 나오는 스택으로 사용할 수 있습니다. 스택을 튜플과 혼동하지 마세요.

## 3. 합, 최댓값, 최솟값

```python
arr = [4, 2, 9]
total = sum(arr)
mx = max(arr)
mn = min(arr)
print(total, mx, mn)  # 15 9 2
```

`total`은 합계, `mx`는 maximum의 줄임말로 최댓값, `mn`은 minimum의 줄임말로 최솟값입니다. `sum`, `max`, `min`은 파이썬 기본 함수입니다. 빈 리스트의 합은 0이지만, 기본값 없이 빈 리스트에 `max`, `min`을 사용하면 오류입니다.

최댓값을 직접 구하면:

```python
arr = [-4, -2, -9]
mx = arr[0]
for x in arr:
    if x > mx:
        mx = x
print(mx)  # -2
```

- `x`는 인덱스가 아니라 리스트에서 꺼낸 실제 값입니다. `-4`, `-2`, `-9`가 차례로 들어갑니다.
- `mx`에는 지금까지 본 값 중 가장 큰 값을 유지합니다.
- `mx = 0`으로 시작하면 모든 값이 음수일 때 틀립니다. 첫 요소로 시작하므로 이 예시는 리스트가 비어 있지 않아야 합니다.

## 4. 카운팅 배열: 인덱스를 값의 이름표로 쓰기

값의 범위가 작으면, 각 값이 몇 번 나왔는지 리스트에 기록할 수 있습니다.

```python
arr = [2, 1, 2, 4, 2, 1]
count = [0] * 5
for x in arr:
    count[x] += 1
print(count)  # [0, 2, 3, 0, 1]
```

`[0] * 5`는 0을 다섯 개 담은 리스트입니다. 이 예시는 값이 `0~4`인 경우에만 사용합니다.

| 인덱스 x | count[x]의 뜻 | 최종 값 |
|---|---|---:|
| 0 | 숫자 0의 등장 횟수 | 0 |
| 1 | 숫자 1의 등장 횟수 | 2 |
| 2 | 숫자 2의 등장 횟수 | 3 |
| 3 | 숫자 3의 등장 횟수 | 0 |
| 4 | 숫자 4의 등장 횟수 | 1 |

`x = 2`를 만날 때마다 `count[2]`가 1씩 증가합니다. `count[x] += 1`은 `count[x] = count[x] + 1`입니다. 점수가 `0~100`이면 인덱스 100도 필요하므로 길이를 101로 만듭니다.

음수는 파이썬에서 뒤쪽 인덱스로 해석되므로 이 방식에 그대로 넣으면 잘못된 집계가 됩니다. 음수가 있거나 값의 범위가 너무 크면 딕셔너리 등 다른 방법을 검토합니다.

### 최빈값과 동점 처리

최빈값은 가장 자주 나온 값입니다. 위 `count`를 사용하면:

```python
best = 0
for score in range(len(count)):
    if count[score] >= count[best]:
        best = score
print(best)  # 2
```

`score`는 지금 확인하는 값, `best`는 지금까지 가장 많이 등장한 값입니다. 빈도를 비교할 때는 `score` 자체가 아니라 `count[score]`를 비교합니다. 작은 값부터 확인하며 `>=`로 교체하므로 동점이면 더 큰 값이 남습니다. `>`로만 교체하면 동점에서는 먼저 본 작은 값이 남습니다. 원본 자료가 비어 있지 않다고 가정합니다.

## 5. 문자열 슬라이싱: [시작:끝:간격]

문자열도 인덱스로 읽을 수 있습니다. 슬라이싱은 범위를 잘라 새 값을 만드는 문법입니다. 끝 인덱스는 포함하지 않습니다.

```python
s = "abcdef"
```

```text
문자:         a   b   c   d   e   f
양수 인덱스:  0   1   2   3   4   5
음수 인덱스: -6  -5  -4  -3  -2  -1
```

| 표현 | 결과 | 읽는 방법 |
|---|---|---|
| `s[1:4]` | `"bcd"` | 1부터 4 직전까지 |
| `s[:3]` | `"abc"` | 처음부터 3 직전까지 |
| `s[-3:]` | `"def"` | 뒤의 세 글자 |
| `s[1:-1]` | `"bcde"` | 양 끝 제외 |
| `s[::2]` | `"ace"` | 처음부터 두 칸씩 |
| `s[1::2]` | `"bdf"` | 인덱스 1부터 두 칸씩 |
| `s[::-1]` | `"fedcba"` | 마지막부터 왼쪽으로 한 칸씩 |
| `s[4:1:-1]` | `"edc"` | 인덱스 4, 3, 2 |

간격을 생략하면 1입니다. 간격이 음수이면 역방향이며, 생략한 시작·끝도 역방향에 맞게 정해집니다. 간격 0은 오류입니다. `s[1:4:-1]`처럼 방향과 범위가 맞지 않으면 빈 문자열이 됩니다.

특히 `s[::-1]`과 `s[:-1:-1]`은 다릅니다. 후자는 끝을 실제 마지막 글자 위치로 지정한 것이므로 빈 문자열입니다. 역방향으로 맨 앞까지 가려면 끝을 생략합니다.

슬라이싱은 리스트에도 적용됩니다. 원본은 바뀌지 않습니다.

```python
arr = [10, 20, 30, 40]
print(arr[::-1])  # [40, 30, 20, 10]
print(arr)       # [10, 20, 30, 40]
```

## 6. 회문: 뒤집어도 같은 문자열

`level`, `abba`처럼 앞뒤가 같은 문자열을 회문이라고 합니다.

```python
s = "level"
if s == s[::-1]:
    print("YES")  # YES
```

길이 `K`인 부분 문자열을 모두 검사할 수도 있습니다.

```python
s = "ababa"
N = len(s)
K = 3
ans = 0
for i in range(N - K + 1):
    part = s[i:i + K]
    if part == part[::-1]:
        ans += 1
print(ans)  # 3
```

- `N`은 전체 길이, `K`는 검사할 구간의 길이입니다. `1 <= K <= N`이라고 가정합니다.
- `i`는 구간의 시작 인덱스입니다. `0, 1, 2`가 됩니다.
- `part`는 잘라낸 부분 문자열입니다. 차례로 `"aba"`, `"bab"`, `"aba"`입니다.
- `ans`는 발견한 회문의 개수입니다. 문자열이 같아도 시작 위치가 다르면 별도 구간입니다.
- 마지막 시작 위치는 `N - K`입니다. `range`의 끝은 제외되므로 `N - K + 1`을 사용합니다.

각 구간을 자르고 비교하는 데 길이 K만큼 작업하므로 전체는 `O((N - K + 1) × K)`입니다.

## 7. 문자열에서 특정 글자 세기

```python
number = 3369
s = str(number)
cnt = s.count("3") + s.count("6") + s.count("9")
print(cnt)  # 4
```

`number`는 정수, `s`는 이를 문자열로 바꾼 값, `cnt`는 count의 줄임말로 개수입니다. `.count("3")`은 문자 `"3"`의 등장 횟수를 셉니다.

같은 일을 반복문으로 작성하면:

```python
s = "3369"
cnt = 0
for ch in s:
    if ch in "369":
        cnt += 1
print(cnt)  # 4
```

`ch`는 character의 줄임말로 한 글자입니다. `ch in "369"`는 그 글자가 `"3"`, `"6"`, `"9"` 중 하나인지 검사합니다.

## 8. 리스트 정렬과 문자열 정렬

```python
arr = [3, 1, 2]
result = arr.sort()
print(arr)     # [1, 2, 3]
print(result)  # None

original = [3, 1, 2]
ordered = sorted(original)
print(original) # [3, 1, 2]
print(ordered)  # [1, 2, 3]
```

`.sort()`는 리스트 자체를 바꾸며 반환값은 `None`입니다. `arr = arr.sort()`라고 쓰면 `arr`에 `None`이 들어가므로 주의합니다. `sorted()`는 새 리스트를 반환합니다. 둘 다 `reverse=True`로 내림차순 정렬할 수 있습니다.

문자열에는 `.sort()`가 없습니다. 문자열은 글자 자체를 교체할 수 없는 타입입니다.

```python
s = "cab"
letters = sorted(s)
result = "".join(letters)
print(letters)  # ['a', 'b', 'c']
print(result)   # abc
print(s)        # cab
```

`sorted(s)`는 정렬된 글자 리스트를 만들고, `"".join(...)`은 문자열 항목들을 사이에 아무것도 넣지 않고 연결합니다. `"-".join(letters)`라면 `a-b-c`입니다. 기본 문자 정렬은 유니코드 순서를 따르므로 대소문자를 섞으면 사람이 생각하는 사전 순서와 다를 수 있습니다.

### 여러 기준으로 정렬하기

이 예시의 각 튜플은 `(이름, 점수)`입니다. 점수 내림차순, 동점이면 이름 오름차순으로 정렬합니다.

```python
students = [("민수", 80), ("영희", 90), ("가영", 90)]

def sort_key(student):
    name = student[0]
    score = student[1]
    return (-score, name)

students.sort(key=sort_key)
print(students)  # [('가영', 90), ('영희', 90), ('민수', 80)]
```

`key`에는 각 항목의 정렬 기준을 만드는 함수를 전달합니다. 기준 튜플은 앞 항목부터 비교하고, 같을 때 다음 항목을 비교합니다. `-score`를 오름차순으로 정렬하면 원래 점수는 큰 것부터 나옵니다.

이 함수만 짧게 쓰면 `students.sort(key=lambda x: (-x[1], x[0]))`입니다. `lambda x: 식`은 x를 받아 식의 결과를 반환하는 이름 없는 함수입니다. `x`는 각 학생 튜플입니다. 이때 콜론은 슬라이싱 문법이 아닙니다.

서로 비교할 수 없는 타입을 섞은 `[1, "a", str]` 같은 리스트는 기본 정렬하면 오류입니다. 섞어 담을 수 있다는 것과 정렬할 수 있다는 것은 별개입니다.

## 9. 양끝 제거 평균

문제가 최솟값·최댓값을 하나씩 제외하라고 요구할 때 사용하는 패턴입니다. 모든 평균에서 양끝을 제외하는 것은 아닙니다.

```python
arr = [100, 20, 10, 40, 30]
arr.sort()                   # [10, 20, 30, 40, 100]
remaining = arr[1:-1]         # [20, 30, 40]
total = sum(remaining)       # 90
count = len(remaining)       # 3
mean = total / count         # 30.0
avg = round(mean)            # 30
print(avg)                   # 30
```

`remaining`은 남은 값들, `total`은 합계, `count`는 남은 개수, `mean`은 평균, `avg`는 반올림한 평균입니다. `/`는 나눗셈이며 결과가 정수로 나누어떨어져도 여기서는 실수입니다.

줄이면 원래 패턴이 됩니다.

```python
avg = round(sum(arr[1:-1]) / (len(arr) - 2))
```

확인할 조건:

- 정렬해야 양끝이 최솟값·최댓값이 됩니다. 정렬하지 않으면 단순히 첫 값과 마지막 값입니다.
- 원소가 최소 3개 있어야 합니다. 2개면 분모가 0입니다.
- 최솟값·최댓값이 여러 개 있어도 각각 하나씩만 제외합니다.
- 극단적인 점수가 평균에 미치는 영향을 줄일 수 있지만, 문제의 요구에 맞춰 적용합니다.
- `round()`가 문제에서 요구하는 반올림인지 확인합니다.

```python
print(round(2.5))  # 2
print(round(3.5))  # 4
```

파이썬 `round()`는 정확히 중간인 경우 가까운 짝수를 선택합니다. C++의 `std::round()`와 다릅니다. 실수는 일부 소수를 정확히 표현하지 못한다는 점도 있습니다.

문제가 '음수가 없는 정수들의 평균에서 정확히 .5이면 올림'을 요구한다면, 위 `total`, `count`에 대해 실수 없이 다음처럼 계산할 수 있습니다.

```python
avg = (2 * total + count) // (2 * count)
```

`//`는 나눗셈의 몫을 아래쪽 정수로 내립니다. 이 식은 해당 조건에 한정한 방법이며 음수까지 일반화해서 사용하면 안 됩니다.

## 10. 반복 문자열을 모아서 합치기

입력이 다음처럼 '문자 반복횟수'로 N줄 주어지는 예시입니다.

```text
2
A 3
B 2
```

```python
N = int(input())
parts = []
for _ in range(N):
    ch, cnt = input().split()
    parts.append(ch * int(cnt))
result = "".join(parts)
print(result)  # AAABB
```

- `N`은 입력 줄 수입니다.
- `ch`는 문자열, `cnt`는 아직 문자열인 반복 횟수입니다. `int(cnt)`로 정수로 바꿉니다.
- `"A" * 3`은 `"AAA"`입니다. 문자열에 정수를 곱하면 반복합니다.
- `parts`는 `['AAA', 'BB']`가 되고, 마지막에 합쳐 `result`를 만듭니다.

## 11. 길이 K인 구간을 전부 보기

```python
arr = [10, 20, 30, 40, 50]
N = len(arr)
K = 3
for i in range(N - K + 1):
    window = arr[i:i + K]
    print(window)
```

출력:

```text
[10, 20, 30]
[20, 30, 40]
[30, 40, 50]
```

`window`는 현재 구간입니다. 여기서는 `1 <= K <= N`입니다. 각 슬라이스는 K개를 복사하므로 반복문이 하나여도 전체가 무조건 `O(N)`은 아닙니다. 구간 합을 많이 묻는 문제라면 5장의 누적합으로 각 합을 `O(1)`에 구할 수 있습니다.
