# 개념집 읽는 방법

함수와 파이썬을 처음 배우는 관점에서, 코드에 나오는 이름과 실행 과정을 함께 설명합니다. C++에서 같은 이름을 보았어도 파이썬에서는 다른 기능일 수 있습니다.

## 예제 코드를 읽을 때

1. 코드 앞의 입력 예시와 전제 조건부터 봅니다.
2. 각 변수에 값, 인덱스, 개수 중 무엇이 들어가는지 확인합니다.
3. 한 번의 반복이나 함수 호출에서 값이 어떻게 바뀌는지 따라갑니다.
4. 직접 예상한 출력과 문서의 결과를 비교합니다.
5. '축약형'이라고 표시한 코드는 앞의 코드를 짧게 쓴 대안입니다. 입력을 두 번 읽으라는 뜻이 아닙니다.

주변 문맥의 변수를 이어 쓰는 짧은 조각도 있습니다. 예를 들어 `board = [... for _ in range(N)]`은 N을 먼저 정해야 합니다. '전체 예시'는 필요한 초기값과 호출까지 포함합니다. 출력 예시는 Python 3 기준입니다.

## 자주 나오는 변수 이름 사전

아래 뜻은 이 개념집의 관례입니다. 파이썬이 의미를 강제하지 않으며, 실제 의미는 해당 코드의 정의를 우선합니다.

| 이름 | 흔한 뜻 | 특히 구분할 것 |
|---|---|---|
| `N`, `M` | 자료의 크기. 격자에서는 행 수·열 수 | 개수이지 마지막 인덱스가 아님 |
| `i`, `j`, `idx` | 인덱스 또는 반복 번호 | `for x in arr`의 x는 보통 실제 값 |
| `r`, `c` | row·column, 행·열 인덱스 | 1차원 구간의 r은 right일 수 있음 |
| `nr`, `nc` | next row·column, 다음 후보 좌표 | 계산 후에도 범위 검사가 필요 |
| `dr`, `dc` | 방향별 행·열 변화량 리스트 | 같은 인덱스끼리 한 방향의 짝 |
| `d` | direction, 방향 번호 | 방향의 순서는 델타를 정의한 코드에서 확인 |
| `sr`, `sc` | 시작 행·열 인덱스 | 현재 처리 위치 r·c와 구분 |
| `depth` | 선택한 단계 수, 재귀 깊이 | 어느 시점에 증가하는지 확인 |
| `total` | 합계 또는 현재 경로에서의 합 | 입력 전체 합인지 선택한 것의 합인지 확인 |
| `cnt`, `count` | 개수 또는 빈도 리스트 | 이름만으로 타입이 정해지지 않음 |
| `ans`, `answer` | 지금까지의 답 | 초깃값이 0인지 무한대인지 이유 확인 |
| `visited`, `used` | 방문·사용 여부 | 탐색 뒤 표시를 복구하는지 확인 |
| `dist` | 시작점으로부터의 거리 | -1 같은 초기 표시의 의미 확인 |
| `prefix` | 누적합 목록·격자 | k가 인덱스인지 앞부분의 개수인지 정의 확인 |
| `dp` | 작은 상태들의 답을 저장한 목록·격자 | 각 칸의 의미는 문제마다 새로 정의 |

설명을 이해했는지 확인하려면 변수 이름을 쉬운 한글 뜻으로 바꿔 읽어보세요. 예를 들어 `nr = r + dr[d]`는 '다음 행 = 현재 행 + 이번 방향의 행 변화량'입니다.
