# Python 자료형, 입력, 출력, 시간복잡도

C++ 경험은 있지만 파이썬과 함수는 처음 배우는 사람을 기준으로 설명합니다. 코드는 먼저 여러 줄로 풀어 이해한 뒤 축약형을 봅니다. 변수 이름은 파이썬이 정해준 이름이 아니라 작성자가 붙인 이름입니다.

## 1. 값, 변수, 타입

```python
age = 20
name = "민수"
```

- `20`, `"민수"`는 실제 값입니다.
- `age`, `name`은 그 값을 가리키는 변수 이름입니다.
- `int`, `str`은 각각 정수 타입과 문자열 타입입니다. 타입은 값의 종류와 가능한 연산을 정합니다.
- `=`는 대입입니다. 같은지 비교할 때는 `==`를 씁니다.
- `#` 뒤는 사람이 읽는 주석입니다. 실행되지 않습니다.

| 타입 이름 | 값의 예 | 의미 |
|---|---|---|
| `int` | `20`, `-3` | 정수 |
| `float` | `3.14` | 실수 |
| `str` | `"hello"`, `"123"` | 문자열. 숫자처럼 보여도 따옴표 안이면 문자열 |
| `bool` | `True`, `False` | 참과 거짓 |
| `list` | `[10, 20]` | 순서가 있고 요소 변경이 가능한 묶음 |
| `tuple` | `(10, 20)` | 순서가 있고 요소 교체가 불가능한 묶음 |
| `dict` | `{"민수": 90}` | 키로 값을 찾는 묶음 |

`print(대상)`은 대상을 출력하고, `type(대상)`은 그 대상의 타입을 알려줍니다.

```python
print(type(20))      # <class 'int'>
print(type("민수"))  # <class 'str'>
```

### 왜 `type(str)`은 `<class 'type'>`일까?

`"str"`과 `str`은 다른 대상입니다. `"str"`은 글자 세 개이고, 따옴표 없는 `str`은 문자열 타입 자체입니다.

파이썬에서는 타입 자체도 변수에 넣거나 출력할 수 있는 객체입니다. 객체는 여기서는 '프로그램에서 다룰 수 있는 대상'이라고 이해하면 됩니다. `str` 같은 기본 타입 객체의 타입이 `type`입니다.

여기서 `type`은 단순히 '자료형'이라는 일반 단어가 아니라 **이름이 실제로 type인 파이썬의 클래스**입니다. `str`이 문자열 값들의 타입이듯, `type`은 str·int 같은 타입 객체들의 타입입니다. 따라서 '타입인 대상도 다시 타입을 물어볼 수 있다'는 점이 핵심입니다.

| 확인할 대상 | 대상의 정체 | 그 대상에 type을 적용한 결과 |
|---|---|---|
| `"안녕"` | 실제 문자열 값 | `<class 'str'>` |
| `str` | 문자열 타입을 나타내는 클래스 객체 | `<class 'type'>` |
| `123` | 실제 정수 값 | `<class 'int'>` |
| `int` | 정수 타입을 나타내는 클래스 객체 | `<class 'type'>` |

```text
"안녕" ── 어떤 타입의 값인가? ──> str
str    ── 이 타입 객체는 어떤 타입인가? ──> type
```

두 화살표 모두 타입을 묻는 관계입니다. 문자열을 변환하는 과정이 아닙니다.

```python
print("str")        # str: 글자를 출력
print(str)          # <class 'str'>: 문자열 타입 자체를 출력
print(type("str"))  # <class 'str'>: 글자 "str"의 타입
print(type(str))    # <class 'type'>: str이라는 타입 객체의 타입
print(type(int))    # <class 'type'>: int도 타입 객체
```

`<class 'str'>`은 'str이라는 클래스'를 나타내는 출력 표현입니다. 여기서 클래스는 값들을 만드는 타입의 정의라고 생각하면 됩니다. 클래스의 코드나 모든 정보가 출력되는 것은 아닙니다. 지금은 클래스 작성법이나 메타클래스를 알 필요는 없습니다.

`str(123)`처럼 괄호를 붙이면 `str`을 호출하여 문자열 값을 만듭니다.

```python
converter = str          # 타입 자체를 변수에 저장
result = converter(123)  # str(123)과 같은 동작
print(result)           # 123: print는 문자열의 따옴표를 표시하지 않음
print(type(result))     # <class 'str'>

items = ["str", str, str(123)]
print(items)            # ['str', <class 'str'>, '123']
```

리스트나 튜플에 타입을 넣어도 타입의 의미는 변하지 않습니다. 첫 항목은 문자열, 두 번째는 타입 자체, 세 번째는 호출 결과인 문자열입니다. 아래의 `map(int, ...)`도 타입 자체를 전달하는 예입니다.

## 2. 코드의 실행 순서와 반복문

기본적으로 위에서 아래로 실행합니다. `:` 다음에 들여쓴 줄들은 하나의 실행 묶음입니다. C++에서 `{}`로 묶던 범위를 파이썬에서는 들여쓰기로 표현합니다. 보통 공백 4칸을 사용합니다.

```python
for i in range(3):
    print(i)
print("끝")
```

출력:

```text
0
1
2
끝
```

- `for`는 반복문입니다. `i`는 매번 꺼낸 값을 받는 변수입니다.
- `range(3)`은 `0, 1, 2`를 차례로 제공합니다. 끝 숫자 `3`은 포함하지 않습니다.
- `range(1, 4)`는 `1, 2, 3`입니다.
- `range(0, 6, 2)`는 `0, 2, 4`입니다. 세 번째 인수는 간격입니다.
- `_`도 변수 이름입니다. 반복 횟수만 필요하고 그 값은 쓰지 않을 때 관례적으로 사용합니다.

## 3. 기본 입력: 한 줄이 어떻게 바뀌는지

`input()`은 한 줄을 읽어 문자열로 돌려줍니다. 입력한 줄 끝의 줄바꿈은 제거합니다.

### 정수 하나

입력이 `5`일 때:

```python
text = input()  # 문자열 "5"
N = int(text)   # 정수 5로 변환
print(N + 1)    # 6
```

`N`은 보통 자료의 개수나 크기를 담는 이름입니다. 예약어가 아니므로 다른 이름을 써도 됩니다. 축약형은 `N = int(input())`입니다. 안쪽의 `input()`부터 실행됩니다.

### 공백으로 구분한 정수 여러 개

입력이 `10 20 30`일 때:

```python
text = input()               # "10 20 30"
pieces = text.split()        # ["10", "20", "30"]
converted = map(int, pieces) # 각 항목에 int를 적용할 map 객체
arr = list(converted)        # [10, 20, 30]
print(arr)                   # [10, 20, 30]
```

- `.split()`은 공백을 기준으로 나눠 문자열 리스트를 만듭니다. 인수가 없으면 연속 공백도 처리합니다.
- `map(함수, 대상)`은 대상의 각 항목에 함수를 적용한 결과를 차례로 제공합니다. 결과는 필요할 때 계산되며, 사용한 map 객체를 처음부터 다시 읽을 수는 없습니다.
- 여기서는 `int()`를 미리 실행하지 않고 `int` 자체를 전달합니다. `map`이 각 항목에 `int(...)`를 실행합니다.
- `list(...)`는 그 결과를 모두 꺼내 리스트로 만듭니다.
- `arr`는 array를 줄인 관례적인 이름입니다. 실제 파이썬 타입은 `list`입니다.

축약형:

```python
arr = list(map(int, input().split()))
```

파이썬의 `map()`은 C++의 `std::map`과 다릅니다. 키와 값을 저장하려면 파이썬에서는 `dict`를 사용합니다.

### 정수 두 개를 변수 두 개에 받기

```python
A, B = map(int, input().split())
print(A + B)
```

입력이 `3 7`이면 `A = 3`, `B = 7`이 되어 `10`을 출력합니다. 여러 값을 여러 변수에 나눠 담는 것을 언패킹이라고 합니다. 이 코드는 입력 값이 정확히 두 개여야 합니다. 값이 부족하거나 많으면 오류가 납니다.

## 4. 2차원 입력과 리스트 컴프리헨션

2차원 배열은 행별 리스트를 바깥 리스트에 담은 구조입니다. 이 예시에서는 `N`이 행 수, `M`이 열 수입니다. 입력 각 행에는 `M`개의 정수가 주어진다고 가정합니다.

입력:

```text
2 3
1 2 3
4 5 6
```

풀어서 작성하면:

```python
N, M = map(int, input().split())
board = []
for _ in range(N):
    row = list(map(int, input().split()))
    board.append(row)
print(board)  # [[1, 2, 3], [4, 5, 6]]
```

- `board`는 전체 격자, `row`는 방금 입력받은 한 행입니다.
- `.append(row)`는 리스트 끝에 `row`를 요소 하나로 추가합니다.
- `range(N)`으로 총 `N`개 행을 읽습니다. `M`은 입력 형식에서 정한 한 행의 길이입니다. 위 코드는 길이를 자동 검사하지는 않습니다.

반복 부분을 줄이면:

```python
board = [list(map(int, input().split())) for _ in range(N)]
```

이 문법이 리스트 컴프리헨션입니다. `[만들 값 for 변수 in 반복 대상]` 형태로, 반복할 때마다 만든 값을 새 리스트에 담습니다. 이 축약형은 `N`을 이미 읽은 뒤 사용하는 입력 부분입니다. 전체 예시를 실행한 다음 또 입력받으라는 뜻이 아닙니다.

문자가 붙어서 들어오는 `ABC` 한 줄은 다음처럼 처리합니다.

```python
row = list("ABC")
print(row)  # ['A', 'B', 'C']
```

`N`줄의 문자 격자는 `board = [list(input()) for _ in range(N)]`으로 읽습니다. 공백으로 나뉜 문자는 대신 `input().split()`을 사용합니다. 행·열·좌표는 3장에서 자세히 설명합니다.

## 5. 빠른 입력과 공백 제거

```python
import sys
input = sys.stdin.readline
text = input().rstrip("\n")
```

- `import sys`는 표준 입출력 기능이 있는 모듈을 불러옵니다.
- `input = sys.stdin.readline`은 이후의 `input()`이 그 함수를 사용하게 합니다. 여기에는 호출 괄호를 붙이지 않습니다.
- `readline()`은 줄 끝의 `\n`을 포함할 수 있습니다.
- `.rstrip("\n")`은 끝의 줄바꿈 문자를 제거합니다.
- `.strip()`은 양쪽 끝의 공백·탭·줄바꿈을 모두 제거합니다. 문자열의 앞뒤 공백도 데이터라면 함부로 사용하면 안 됩니다.

정수는 `int(input())`, 공백 구분 숫자는 `input().split()`이 보통 줄바꿈까지 처리하므로 별도 `strip()`이 필요하지 않습니다.

## 6. SWEA형 출력과 f-string

`T`는 테스트 케이스 수, `tc`는 현재 테스트 케이스 번호, `ans`는 그 케이스의 답을 뜻하는 관례적인 이름입니다.

아래는 출력 형식만 연습하는 예시입니다. 실제 문제에서는 `ans = 0`을 답을 계산하는 코드로 바꿉니다.

```python
T = int(input())
for tc in range(1, T + 1):
    ans = 0
    print(f"#{tc} {ans}")
```

입력이 `2`이면 출력은 다음과 같습니다.

```text
#1 0
#2 0
```

- `range(1, T + 1)`은 `1`부터 `T`까지입니다. 끝을 포함하지 않으므로 `+ 1`이 필요합니다.
- `f"..."`는 문자열 안의 `{변수}`를 실제 값으로 바꾸는 f-string입니다.
- `#`는 문자열 안의 글자이므로 주석이 아닙니다.

```python
tc = 1
arr = [10, 20, 30]
print(f"#{tc}", *arr)  # #1 10 20 30
```

`*arr`는 리스트의 요소들을 각각의 인수로 펼칩니다. 위 호출은 `print("#1", 10, 20, 30)`과 같습니다. `print`는 기본적으로 인수 사이에 공백을 넣습니다.

## 7. 함수: 입력값, 처리, 반환값

함수는 처리 과정을 이름으로 묶어 재사용하는 방법입니다.

```python
def add(a, b):
    result = a + b
    return result

answer = add(3, 5)
print(answer)  # 8
```

- `def`는 함수 정의입니다. 정의만으로 본문이 실행되지는 않습니다.
- `a`, `b`는 함수가 받을 값을 담는 매개변수입니다.
- `add(3, 5)`가 호출되면 이번 호출의 `a`에 `3`, `b`에 `5`가 들어갑니다.
- `return`은 함수를 끝내고 호출한 곳으로 결과를 전달합니다. `print`는 화면에 출력할 뿐, 결과를 돌려주는 기능과 다릅니다.
- `return` 없이 끝나거나 `return`만 실행하면 `None`을 반환합니다. `None`은 '결과가 없음'을 표현하는 값입니다.

행·열 범위 검사도 함수로 분리할 수 있습니다.

```python
def in_range(r, c, N, M):
    return 0 <= r < N and 0 <= c < M

print(in_range(1, 2, 3, 4))  # True
print(in_range(3, 2, 3, 4))  # False
```

`r`은 행 인덱스, `c`는 열 인덱스, `N`은 행 수, `M`은 열 수입니다. 행이 3개이면 인덱스는 `0, 1, 2`이므로 행 `3`은 범위 밖입니다. `and`는 두 조건이 모두 참이어야 참입니다.

## 8. 리스트 복사와 같은 대상을 가리키는 문제

```python
a = [10, 20]
b = a
b[0] = 99
print(a)  # [99, 20]
```

`b = a`는 리스트를 복사하지 않습니다. 두 이름이 같은 리스트를 가리킵니다. 새 리스트가 필요하면 슬라이싱 `[:]` 등으로 복사합니다.

```python
a = [10, 20]
b = a[:]
b[0] = 99
print(a)  # [10, 20]
print(b)  # [99, 20]
```

2차원 리스트는 행도 리스트라는 점을 고려해야 합니다.

```python
a = [[1, 2], [3, 4]]
b = a[:]                     # 바깥 리스트만 새로 생성. 행은 공유
c = [row[:] for row in a]     # 각 행까지 새로 생성
b[0][0] = 99
print(a)  # [[99, 2], [3, 4]]
print(c)  # [[1, 2], [3, 4]]
```

`row`는 `a`에서 하나씩 꺼낸 행입니다. 숫자로 된 2차원 격자는 행별 복사로 충분합니다. 행 안에 다시 변경 가능한 객체가 있다면 그 안쪽까지 복사되는 것은 아닙니다.

## 9. 시간복잡도: 입력이 커지면 작업이 얼마나 늘까?

시간복잡도는 정확한 초가 아니라 입력 크기에 따른 작업량의 증가를 표현합니다. `O`는 빅오라고 읽습니다. 이 표에서 `N`은 데이터 개수입니다.

| 표현 | 예시 | N = 1,000일 때 대략적인 규모 |
|---|---|---:|
| `O(1)` | 리스트 인덱스 한 번 읽기 | 일정 |
| `O(N)` | 전체를 한 번 반복 | 1,000 |
| `O(N log N)` | 일반적인 비교 정렬의 최악 작업량 | 약 10,000 |
| `O(N²)` | N번 반복 안에서 다시 N번 반복 | 1,000,000 |
| `O(2ᴺ)` | 부분집합 전부 검사 | 매우 큼 |
| `O(N!)` | 모든 순서 나열 | 매우 큼 |

`log`는 여기서는 대략 '몇 번 반으로 줄일 수 있는가'로 생각하면 됩니다. `!`는 팩토리얼로, `4! = 4 × 3 × 2 × 1 = 24`입니다. 수학의 `2ᴺ`을 코드로 쓰면 `2 ** N`입니다. 파이썬의 `^`는 거듭제곱이 아닙니다.

```python
N = 3
count = 0
for i in range(N):
    for j in range(N):
        count += 1
print(count)  # 9: 3 × 3번 실행
```

`i`, `j`는 각각 바깥 반복과 안쪽 반복의 번호이고, `count`는 실행 횟수입니다. `count += 1`은 `count = count + 1`과 같습니다.

풀이를 고를 때의 대략적인 출발점:

| 입력 크기 | 먼저 검토할 작업량 |
|---|---|
| N이 10 안팎 | 순열도 후보. 10!은 약 363만이므로 경우당 작업량까지 확인 |
| N이 20 안팎 | 부분집합도 후보. 2²⁰은 약 105만 |
| N이 1,000 안팎 | N²은 약 100만이므로 2중 반복도 충분히 검토 |
| N이 100,000 안팎 | N 또는 N log N 위주 |
| N이 1,000,000 안팎 | N 위주로 검토하되 입력·메모리도 확인 |

이 표는 통과 보장이 아닙니다. 제한 시간, 테스트 케이스 수, 내부 작업에 따라 달라집니다. 격자는 한 변만 보지 말고 `N × M`개의 칸을 계산해야 합니다. BFS/DFS도 이름만으로 가능한 입력 크기가 정해지지 않습니다. 상세 연습은 `../06_시간복잡도_입력크기_완전기초/`에 있습니다.

## 10. 시험장에서 확인할 순서

1. 입력 줄마다 무엇이 들어오는지 적습니다.
2. 각 변수에 '개수'를 넣는지 '인덱스'를 넣는지 구분합니다.
3. 작은 예시로 손으로 실행한 뒤 코드를 작성합니다.
4. 전체 작업량과 메모리를 확인합니다.
5. 짧게 쓰는 것보다 조건이 분명한 코드를 우선합니다.
