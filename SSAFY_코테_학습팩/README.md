# SSAFY 코테 학습팩

이 폴더는 외부 사이트를 열지 않고도 SSAFY 코딩 테스트 대비를 한 바퀴 돌 수 있게 만든 자습용 자료입니다.

주의: 실제 SSAFY 공식 기출문제를 복제한 자료가 아니라, 공개적으로 자주 알려진 SWEA/SSAFY형 출제 패턴을 바탕으로 만든 자작 예상 문제와 연습 문제입니다. 합격을 보장할 수는 없지만, 구현력과 시뮬레이션, 2차원 배열, 완전탐색, BFS/DFS, 백트래킹을 집중적으로 훈련하도록 구성했습니다.

## 추천 학습 순서

1. `00_로드맵/README.md`
   - 전체 학습 순서와 목표 시간을 확인합니다.
2. `01_개념집`
   - Python 입력, 배열, 문자열, 델타 탐색, 완전탐색, BFS/DFS, DP 기초를 먼저 봅니다.
3. `02_난이도별_문제`
   - `D1_기초 -> D2_구현 -> D3_핵심 -> D4_실전` 순서로 풉니다.
   - 각 폴더는 `문제.md`, `해설.md`, `solutions.py`로 나뉩니다.
4. `03_예상기출_모의고사`
   - 시간을 재고 실전처럼 풉니다.
5. `04_코드템플릿`
   - 시험 직전에 반복해서 볼 기본 코드를 모았습니다.
6. `05_오답노트`
   - 틀린 이유를 유형별로 기록합니다.
7. `06_시간복잡도_입력크기_완전기초`
   - 입력 크기와 시간복잡도를 처음부터 익힙니다.

## 난이도 기준

| 폴더 | 목표 |
|---|---|
| D1_기초 | 입력, 반복문, 리스트, 문자열, 카운팅을 실수 없이 작성 |
| D2_구현 | 2차원 배열, 회전, 달팽이, 마름모, 조건 시뮬레이션 |
| D3_핵심 | 큐, 스택, 완전탐색, BFS/DFS, 부분집합 |
| D4_실전 | SSAFY형 고난도 구현, 백트래킹, 상태 관리 |

## 공부 규칙

- 문제를 보자마자 코드를 치지 말고, 먼저 입력 크기를 보고 시간복잡도를 정합니다.
- 2차원 배열 문제는 항상 `범위 체크`, `방문 처리`, `방향 배열`을 먼저 떠올립니다.
- 완전탐색은 가능한 경우의 수를 먼저 계산합니다.
- 한 문제를 틀리면 코드만 고치지 말고 `왜 틀렸는지`를 오답노트에 적습니다.
- 해설 코드는 정답 확인용입니다. 먼저 직접 풀이한 뒤 비교하세요.

## 기존 자료와의 관계

현재 폴더의 `SSAFY_SWEA_Python_Crash.md`는 SWEA 번호 기반 빠른 풀이집입니다. 이 학습팩은 번호 암기보다 개념별 사고와 난이도 상승 훈련에 맞춰 구성했습니다.
