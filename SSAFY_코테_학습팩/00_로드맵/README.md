# SSAFY 코테 4주 로드맵

## 1주차: Python 기초와 D1

목표: 입력과 출력, 반복문, 리스트, 문자열 처리에서 실수하지 않는 상태를 만듭니다.

- `01_개념집/01_python_입출력_시간복잡도.md`
- `01_개념집/02_배열_문자열_카운팅.md`
- `02_난이도별_문제/D1_기초`

체크 기준:

- `T = int(input())` 형식 문제를 막힘없이 작성할 수 있다.
- `#1 answer` 형식 출력에서 공백과 줄바꿈을 실수하지 않는다.
- 리스트 합, 최댓값, 최솟값, 카운팅 배열을 직접 구현할 수 있다.

## 2주차: 2차원 배열과 D2

목표: 달팽이, 회전, 마름모, 파리채 같은 구현형 문제를 안정적으로 풉니다.

- `01_개념집/03_2차원_델타_시뮬레이션.md`
- `02_난이도별_문제/D2_구현`

체크 기준:

- `dr`, `dc` 방향 배열을 자연스럽게 쓴다.
- 배열 회전 공식을 외우지 않고도 유도할 수 있다.
- 범위 밖 접근을 막는 조건문을 먼저 작성한다.

## 3주차: 완전탐색, DFS/BFS, D3

목표: 경로 탐색, 부분집합, 큐/스택 문제를 풀 수 있게 만듭니다.

- `01_개념집/04_완전탐색_재귀_DFS_BFS.md`
- `02_난이도별_문제/D3_핵심`

체크 기준:

- BFS에서 큐에 넣는 시점에 방문 체크를 한다.
- DFS에서 재귀 종료 조건을 먼저 작성한다.
- 부분집합 문제에서 가지치기 조건을 넣을 수 있다.

## 4주차: 실전형 백트래킹과 모의고사

목표: 2시간 안에 구현형 2문제 이상을 완성하는 실전 감각을 만듭니다.

- `01_개념집/05_정렬_그리디_누적합_DP.md`
- `02_난이도별_문제/D4_실전`
- `03_예상기출_모의고사`

체크 기준:

- 조건이 많은 문제를 함수로 나눠서 관리한다.
- 방문 배열과 원본 배열을 섞어 쓰지 않는다.
- 시간 제한 안에 완성 못 했을 때 버릴 풀이와 살릴 풀이를 판단한다.
